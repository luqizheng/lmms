# Phase 4.4 — `iam.permission.changed` 事件 + perm-epoch 令牌失效（双写）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iam 在三类权限变更（assign_permissions / role 禁删 / permission 禁删）的事务里展开受影响 user_ids、发 `iam.permission.changed` 事件、commit 后直写 Redis `perm_epoch:{uid}`；gateway `auth_middleware` 比对 `token.iat < perm_epoch` → 401 强制重认证；gateway 再消费该事件用 set-if-greater 兜底补写 perm_epoch，关闭直写 fail-open 窗口。

**Architecture:** 复用 Phase 4 事务性 outbox（`MySqlOutboxRepo`）+ 4.2 的 `iam.#`→audit 自动落库 + 4.3 的 `subscribe_ephemeral`（gateway 兜底 consumer 用 per-replica ephemeral 队列）。perm_epoch 是 user-level Redis 戳，TTL = access-token TTL，自清。失效判据 `iat < epoch` 全序、无并发漏网。

**Tech Stack:** Rust / axum / sqlx(MySQL) / redis(ConnectionManager + Lua) / lapin(RabbitMQ) / Node codegen / testcontainers。

**Spec:** `docs/superpowers/specs/2026-06-27-phase4.4-permission-changed-design.md`

## Global Constraints

- 事件契约**只改 `contracts/events.yaml`**；Rust 由 `node scripts/contracts-gen.js` 生成；`events.rs`/`routing_keys.rs` 标 DO NOT EDIT MANUALLY。`node scripts/contracts-gen.js --check` 必须 in-sync。
- iam 表前缀 `iam_`；CI 门禁 `node scripts/check-db-naming.js` 必须 PASS。（本期**不新建表**——perm_epoch 只在 Redis；事件走既有 `iam_outbox_events`。）
- **perm_epoch key 两端必须完全一致**：`{prefix}perm_epoch:{user_id}`。gateway 用 `cfg.redis.prefix`；iam 必须用相同 prefix（本计划给 iam RedisConfig 加 `prefix` 字段，默认与 gateway 默认一致）。key 不一致 = 失效静默失败（成功标准 #7）。
- **set-if-greater 单调性**：perm_epoch 写入永远取较大值（iam 直写与 gateway consumer 兜底可能乱序到达；晚到的较小值不得覆盖）。iam 直写与 consumer 兜底**共用同一** Lua set-if-greater 实现。
- perm_epoch TTL = `access_token_ttl_minutes * 60`（iam 配置已有 `jwt.access_token_ttl_minutes: 15`）。
- gateway perm_epoch 读失败 → **fail-open 放行**（与现有 blacklist 一致）。
- iam Redis 连接用 `Option`：Redis 不可用时 iam 仍能启动，直写降级为 no-op（靠 gateway consumer 兜底）。
- iam 直写在业务事务 **commit 之后**（早写只会让旧 token 早失效，不漏失效）。
- `update` 仅在 status 由非 disabled → disabled 时才触发失效（避免改名等无关更新误失效）。
- Rust 在 Docker musl builder 构建/测试；offline 编译需 `--network host` + `SWAGGER_UI_DOWNLOAD_URL=https://gh-proxy.org/https://github.com/swagger-api/swagger-ui/archive/refs/tags/v5.17.14.zip`；testcontainers 测试需挂 `/var/run/docker.sock`。

## 数据流（ASCII）

```
                                   ┌─────────────── iam-service ───────────────┐
admin: assign_permissions /        │ role_svc / permission_svc 写操作 (ONE TX): │
       role|permission 禁用/删除 ──▶│  1. 业务写 (DELETE/INSERT/UPDATE)          │
                                   │  2. 展开受影响 user_ids (SELECT user_roles)│
                                   │  3. enqueue IamPermissionChanged → outbox  │
                                   │  COMMIT                                    │
                                   │  4. (commit 后) iam 直写 perm_epoch:{uid}  │ ← 即时主路径
                                   └────────────────────────────────────────────┘
                                          │ (outbox)                 │ Redis SET-if-greater
                  iam-outbox-publisher ───┘                          ▼
                          │ rk=iam.permission.changed         perm_epoch:{uid} (Redis, EX ttl)
        events exchange ──┼───────────────┬──────────────────────────▲
                          ▼               ▼ (iam.# 绑定)              │ set-if-greater 兜底
              gateway ephemeral queue   audit.iam-events             │
                  │ consume             │ → audit_events (零改动)     │
                  ▼                                                   │
        for uid: set_perm_epoch_if_greater(uid, occurred_at) ────────┘ ← 强一致补偿

        ┌─────────── gateway auth_middleware (每非公开请求) ───────────┐
        │ validate JWT → blacklist EXISTS + perm_epoch GET (pipeline) │
        │ if iat < perm_epoch → 401 "permissions changed"             │
        │ else 放行                                                   │
        └──────────────────────────────────────────────────────────────┘
```

- [ ] **Step 1: 写 `perm_epoch.rs`**

```rust
//! Shared perm-epoch primitive (Phase 4.4).
//! Key: `{prefix}perm_epoch:{user_id}` = unix-seconds of the user's last
//! permission change. Writers (iam direct + gateway consumer backfill) MUST
//! use set-if-greater so out-of-order writes never lower the epoch (which
//! would resurrect already-invalidated tokens). gateway compares token.iat
//! against this; iat < epoch ⇒ token issued before the change ⇒ reject.
use redis::aio::ConnectionLike;

pub fn perm_epoch_key(prefix: &str, user_id: &str) -> String {
    format!("{prefix}perm_epoch:{user_id}")
}

const SET_IF_GREATER: &str = r#"
local cur = redis.call('GET', KEYS[1])
if (not cur) or (tonumber(cur) < tonumber(ARGV[1])) then
  redis.call('SET', KEYS[1], ARGV[1], 'EX', ARGV[2])
end
return 1
"#;

pub async fn set_perm_epoch_if_greater<C: ConnectionLike + Send>(
    conn: &mut C, prefix: &str, user_id: &str, ts: i64, ttl_sec: u64,
) -> Result<(), redis::RedisError> {
    let key = perm_epoch_key(prefix, user_id);
    redis::Script::new(SET_IF_GREATER)
        .key(key).arg(ts).arg(ttl_sec as i64)
        .invoke_async::<_, i64>(conn).await?;
    Ok(())
}

pub async fn get_perm_epoch<C: ConnectionLike + Send>(
    conn: &mut C, prefix: &str, user_id: &str,
) -> Result<Option<i64>, redis::RedisError> {
    let key = perm_epoch_key(prefix, user_id);
    redis::cmd("GET").arg(key).query_async(conn).await
}
```

```rust
use digua_common_event::{Envelope, MySqlOutboxRepo, OutboxRepo, events::IamPermissionChanged};
use digua_common_event::perm_epoch::set_perm_epoch_if_greater;
use sqlx::{MySql, Transaction};
use crate::state::AppState;

/// 在业务事务内 enqueue 事件（与业务写原子）。user_ids 空 → 跳过。
pub async fn enqueue_permission_changed(
    tx: &mut Transaction<'_, MySql>, db: &sqlx::MySqlPool,
    user_ids: &[String], reason: &str, actor_id: Option<&str>,
) -> Result<(), crate::error::IamError> {
    if user_ids.is_empty() { return Ok(()); }
    let env = Envelope::new("iam-service", IamPermissionChanged {
        user_ids: serde_json::json!(user_ids),
        reason: reason.to_string(),
        actor_id: actor_id.map(|s| s.to_string()),
    });
    MySqlOutboxRepo::new(db.clone()).enqueue(tx, &env).await
        .map_err(|e| crate::error::IamError::Internal(e.to_string()))?;
    Ok(())
}

/// commit 后 best-effort 直写 perm_epoch（失败仅 warn；gateway consumer 兜底）。
pub async fn stamp_perm_epochs(state: &AppState, user_ids: &[String]) {
    let Some(conn) = state.redis.as_ref() else { return; };
    let now = chrono::Utc::now().timestamp();
    let mut conn = conn.clone();
    for uid in user_ids {
        if let Err(e) = set_perm_epoch_if_greater(&mut conn, &state.redis_prefix, uid, now, state.perm_epoch_ttl_sec).await {
            tracing::warn!(error=%e, uid, "iam direct perm_epoch write failed (gateway consumer will backfill)");
        }
    }
}
```

```rust
}
```

```rust
//! gateway 兜底 consumer：订阅 iam.permission.changed，set-if-greater 补写 perm_epoch。
//! 关闭 iam 直写的 fail-open 窗口。使用 event.occurred_at 作为 epoch 值（与 iam 直写同时间基准）。
use digua_common_event::events::IamPermissionChanged;
use digua_common_event::{Consumer, Envelope, HandlerError, RabbitMqConsumer};
use digua_common_event::perm_epoch::set_perm_epoch_if_greater;
use redis::aio::MultiplexedConnection;
use std::time::Duration;
use tracing::{info, warn};

const BINDING: &str = "iam.permission.changed";

pub async fn run(conn: MultiplexedConnection, prefix: String, ttl_sec: u64, event_bus_url: String) -> anyhow::Result<()> {
    let backoff = Duration::from_secs(5);
    loop {
        match try_subscribe(conn.clone(), prefix.clone(), ttl_sec, &event_bus_url).await {
            Ok(consumer) => {
                while consumer.connection().status().connected() {
                    tokio::time::sleep(Duration::from_secs(5)).await;
                }
                warn!("perm_epoch consumer connection lost, resubscribing");
            }
            Err(e) => { warn!(error=%e, "perm_epoch consumer subscribe failed, retry in 5s"); tokio::time::sleep(backoff).await; }
        }
    }
}

async fn try_subscribe(conn: MultiplexedConnection, prefix: String, ttl_sec: u64, url: &str) -> anyhow::Result<RabbitMqConsumer> {
    let consumer = RabbitMqConsumer::new(url).await?;
    consumer.subscribe_ephemeral::<IamPermissionChanged, _, _>(&[BINDING], move |env: Envelope<IamPermissionChanged>| {
        let mut conn = conn.clone(); let prefix = prefix.clone();
        async move {
            let users: Vec<String> = serde_json::from_value(env.payload.user_ids.clone()).unwrap_or_default();
            let ts = env.occurred_at.timestamp();
            for uid in users {
                if let Err(e) = set_perm_epoch_if_greater(&mut conn, &prefix, &uid, ts, ttl_sec).await {
                    warn!(error=%e, uid, "perm_epoch backfill failed");
                }
            }
            Ok::<(), HandlerError>(())
        }
    }).await?;
    info!("perm_epoch consumer subscribed (ephemeral) to {}", BINDING);
    Ok(consumer)
}
```
> 确认 `Envelope.occurred_at` 是 `DateTime<Utc>`（4.x 既有），`.timestamp()` 得秒。确认 `RabbitMqConsumer::connection()` 公开（4.3 已用）。
