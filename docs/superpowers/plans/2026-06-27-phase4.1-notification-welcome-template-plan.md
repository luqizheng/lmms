# Phase 4.1: notification-service Welcome Template Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Have notification-service subscribe to `iam.user.created` via the shared event bus and auto-generate a per-user welcome announcement (rendered from a stored template, idempotent on `event_id`).

**Architecture:** notification-service spawns a long-running RabbitMQ consumer at startup (mirroring audit-service's pattern). The consumer binds queue `notification.iam-events` to `events` exchange with routing key `iam.user.created`. On each delivery, it (1) skips already-processed `event_id`s via a new `ntf_event_idempotency` table, (2) loads the `welcome` row from a new `ntf_templates` table (falling back to in-code defaults if missing), (3) renders three placeholders against the envelope, (4) inserts a `published` announcement + recipient + delivery row + idempotency row in one transaction, and (5) bumps the recipient's unread counter and pushes a WebSocket event if they're connected.

**Tech Stack:** Rust 2021, axum, sqlx (MySQL only — notification-service is MySQL-only), tokio, common-event (lapin under the hood), serde_json, tracing.

## Global Constraints

- Table prefix: every new notification-service table MUST start with `ntf_` (CI gate: `node scripts/check-db-naming.js`).
- Code style: NO comments in implementation files unless the existing file already has comments in a similar location (notification-service files are intentionally comment-free except `db.rs`).
- Re-use `common-event` crate for envelope/consumer/routing-key constants. Never hand-roll the AMQP plumbing.
- The producer-side payload is already defined: `common_event::events::IamUserCreated { user_id, username, email, org_unit_id }`. Do NOT change it.
- `user_id` columns are `VARCHAR(32)` everywhere in notification-service (see `2026_06_21_user_id_string.sql`). New tables that reference users must follow this.
- Event bus URL env var: `EVENT_BUS_URL`, default `amqp://guest:guest@localhost:5672/%2f` (matches audit-service exactly).
- Queue topology is pre-declared in `infrastructure/config/rabbitmq/definitions.json`. We add the new queue + binding to that file; the consumer also re-declares idempotently (lapin best practice) so dev without compose still works.
- `tracing::info!` / `tracing::warn!` for all consumer lifecycle events (event_id, event_type, user_id labels), aligning with audit-service.
- Existing migration mechanism: `Db::ensure_schema()` in `src/db.rs` reads `INIT_SQL`+`USER_ID_STRING_SQL` via `include_str!` and splits on `;`. New migrations must be added to that same mechanism in the same idempotent style.
- Default placeholder values (from spec §"Placeholder Defaults"):
  - `{{username}}` → `"New User"`
  - `{{dept_name}}` → `"Platform"`
  - `{{created_at}}` → `"Just now"`

```rust
use std::collections::HashMap;

pub fn render_template(template: &str, vars: &HashMap<&'static str, String>) -> String {
    let mut out = template.to_string();
    for (k, v) in vars {
        let patterns = [
            format!("{{{{{}}}}}", k),
            format!("{{{{ {} }}}}", k),
        ];
        for p in &patterns {
            out = out.replace(p, v);
        }
    }
    out
}
```

```rust
use sqlx::mysql::MySqlPool;
use sqlx::Row;
use tracing::warn;

pub struct WelcomeTemplate {
    pub title: String,
    pub body: String,
}

impl WelcomeTemplate {
    pub fn fallback() -> Self {
        Self {
            title: "Welcome to the platform, {{username}}!".to_string(),
            body: "Hi {{username}}, welcome aboard. You have been added to {{dept_name}} on {{created_at}}. Have a great start!".to_string(),
        }
    }
}

pub async fn load_welcome_template(pool: &MySqlPool) -> WelcomeTemplate {
    match sqlx::query("SELECT title, body FROM ntf_templates WHERE code = 'welcome'")
        .fetch_optional(pool)
        .await
    {
        Ok(Some(row)) => {
            let title: String = row.try_get("title").unwrap_or_default();
            let body: String = row.try_get("body").unwrap_or_default();
            if title.is_empty() || body.is_empty() {
                warn!("welcome template row empty, using fallback");
                WelcomeTemplate::fallback()
            } else {
                WelcomeTemplate { title, body }
            }
        }
        Ok(None) => {
            warn!("welcome template not found, using fallback");
            WelcomeTemplate::fallback()
        }
        Err(e) => {
            warn!(error = %e, "welcome template query failed, using fallback");
            WelcomeTemplate::fallback()
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn fallback_template_is_non_empty() {
        let t = WelcomeTemplate::fallback();
        assert!(!t.title.is_empty());
        assert!(!t.body.is_empty());
        assert!(t.body.contains("{{username}}"));
        assert!(t.body.contains("{{dept_name}}"));
        assert!(t.body.contains("{{created_at}}"));
    }
}
```

## Task 4: Welcome announcement orchestrator (transactional, idempotent)

**Files:**
- Modify: `services/notification-service/src/service/announcement_service.rs` (append `ensure_welcome_for_user`)

**Interfaces:**
- Consumes:
  - `WelcomeTemplate` + `load_welcome_template` from Task 3.
  - `crate::consumer::placeholder::render_template` from Task 2.
  - `common_event::events::IamUserCreated`.
  - `crate::redis_cli::RedisCli::incr_unread`.
  - `crate::ws_hub::WsHub::publish` + `crate::ws_hub::WsOut::New`.
- Produces:
  ```rust
  pub async fn ensure_welcome_for_user(
      pool: &sqlx::mysql::MySqlPool,
      redis: &crate::redis_cli::RedisCli,
      hub: &crate::ws_hub::WsHub,
      event_id: uuid::Uuid,
      user_id: &str,
      payload: &common_event::events::IamUserCreated,
      occurred_at: chrono::DateTime<chrono::Utc>,
  ) -> anyhow::Result<bool>;
  ```
  Returns `Ok(true)` when a new announcement was inserted, `Ok(false)` when the event_id was already processed.

Behavior (inside one transaction):
1. `INSERT INTO ntf_event_idempotency (event_id, event_type) VALUES (?, 'iam.user.created')` with `ON DUPLICATE KEY UPDATE event_id = event_id`. Capture `rows_affected()` — if 0, the event was already processed → commit empty tx and return `Ok(false)`.
2. Compute placeholders:
   - `username` = `payload.username` if non-empty else `"New User"`.
   - `dept_name` = `payload.org_unit_id` if `Some(s)` and non-empty else `"Platform"`.
   - `created_at` = `occurred_at.format("%Y-%m-%d %H:%M UTC").to_string()` if `occurred_at` is non-zero else `"Just now"`.
3. Load template via `load_welcome_template(pool)`. Render both `title` and `body`.
4. `INSERT INTO ntf_announcements ... status='published', publish_at = NOW(), pinned=0, popover=0, created_by='system'` — capture `last_insert_id()`.
5. `INSERT INTO ntf_announcement_recipients (announcement_id, scope_type, scope_id) VALUES (?, 'user', user_id)`.
6. `INSERT INTO ntf_announcement_deliveries (announcement_id, user_id, delivered_at) VALUES (?, ?, NOW())`.
7. Commit. Outside the tx, bump unread + push WebSocket (best-effort, errors logged only).

- [ ] **Step 1: Append the orchestrator implementation**

In `services/notification-service/src/service/announcement_service.rs`, after `load_welcome_template`, add:

```rust
use crate::consumer::placeholder::render_template;
use crate::redis_cli::RedisCli;
use crate::ws_hub::{WsHub, WsOut};
use chrono::{DateTime, Utc};
use common_event::events::IamUserCreated;
use std::collections::HashMap;
use tracing::info;
use uuid::Uuid;

pub async fn ensure_welcome_for_user(
    pool: &MySqlPool,
    redis: &RedisCli,
    hub: &WsHub,
    event_id: Uuid,
    user_id: &str,
    payload: &IamUserCreated,
    occurred_at: DateTime<Utc>,
) -> anyhow::Result<bool> {
    let mut tx = pool.begin().await?;

    let ins = sqlx::query(
        "INSERT INTO ntf_event_idempotency (event_id, event_type) \
         VALUES (?, 'iam.user.created') \
         ON DUPLICATE KEY UPDATE event_id = event_id",
    )
    .bind(event_id.to_string())
    .execute(&mut *tx)
    .await?;
    if ins.rows_affected() == 0 {
        tx.commit().await?;
        info!(event_id = %event_id, user_id = %user_id, "welcome event already processed, skipping");
        return Ok(false);
    }

    let mut vars: HashMap<&'static str, String> = HashMap::new();
    vars.insert(
        "username",
        if payload.username.is_empty() {
            "New User".to_string()
        } else {
            payload.username.clone()
        },
    );
    vars.insert(
        "dept_name",
        match payload.org_unit_id.as_deref() {
            Some(s) if !s.is_empty() => s.to_string(),
            _ => "Platform".to_string(),
        },
    );
    vars.insert(
        "created_at",
        if occurred_at.timestamp() <= 0 {
            "Just now".to_string()
        } else {
            occurred_at.format("%Y-%m-%d %H:%M UTC").to_string()
        },
    );

    let tpl = load_welcome_template(pool).await;
    let title = render_template(&tpl.title, &vars);
    let body = render_template(&tpl.body, &vars);

    let res = sqlx::query(
        "INSERT INTO ntf_announcements \
         (title, body, publish_at, expire_at, pinned, popover, status, created_by, created_at) \
         VALUES (?, ?, NOW(), NULL, 0, 0, 'published', 'system', NOW())",
    )
    .bind(&title)
    .bind(&body)
    .execute(&mut *tx)
    .await?;
    let ann_id = res.last_insert_id();

    sqlx::query(
        "INSERT INTO ntf_announcement_recipients (announcement_id, scope_type, scope_id) \
         VALUES (?, 'user', ?)",
    )
    .bind(ann_id)
    .bind(user_id)
    .execute(&mut *tx)
    .await?;

    sqlx::query(
        "INSERT IGNORE INTO ntf_announcement_deliveries (announcement_id, user_id, delivered_at) \
         VALUES (?, ?, NOW())",
    )
    .bind(ann_id)
    .bind(user_id)
    .execute(&mut *tx)
    .await?;

    tx.commit().await?;

    if let Err(e) = redis.incr_unread(user_id.to_string(), 1).await {
        warn!(error = %e, user_id = %user_id, "incr_unread failed (non-fatal)");
    }
    hub.publish(
        user_id.to_string(),
        WsOut::New(serde_json::json!({
            "id": ann_id,
            "title": title,
            "pinned": false,
            "popover": false,
        })),
    )
    .await;

    info!(event_id = %event_id, user_id = %user_id, ann_id, "welcome announcement created");
    Ok(true)
}
```

```rust
pub mod iam_events;
pub mod placeholder;

use std::time::Duration;

use common_event::events::IamUserCreated;
use common_event::{Consumer, Envelope, RabbitMqConsumer};
use sqlx::mysql::MySqlPool;
use tracing::{info, warn};

use crate::redis_cli::RedisCli;
use crate::ws_hub::WsHub;

const QUEUE_NAME: &str = "notification.iam-events";
const BINDING: &str = "iam.user.created";

pub async fn run(
    pool: MySqlPool,
    redis: RedisCli,
    hub: WsHub,
    event_bus_url: String,
) -> anyhow::Result<()> {
    let backoff = Duration::from_secs(5);
    loop {
        match try_subscribe(pool.clone(), redis.clone(), hub.clone(), &event_bus_url).await {
            Ok(()) => {
                tokio::time::sleep(Duration::from_secs(30)).await;
            }
            Err(e) => {
                warn!(error = %e, "notification consumer subscribe failed, retry in 5s");
                tokio::time::sleep(backoff).await;
            }
        }
    }
}

async fn try_subscribe(
    pool: MySqlPool,
    redis: RedisCli,
    hub: WsHub,
    event_bus_url: &str,
) -> anyhow::Result<()> {
    let consumer = RabbitMqConsumer::new(event_bus_url).await?;
    consumer
        .subscribe::<IamUserCreated, _, _>(
            QUEUE_NAME,
            &[BINDING],
            move |env: Envelope<IamUserCreated>| {
                let pool = pool.clone();
                let redis = redis.clone();
                let hub = hub.clone();
                async move { iam_events::handle_iam_user_created(&pool, &redis, &hub, &env).await }
            },
        )
        .await?;
    info!("notification consumer subscribed to {} ({})", QUEUE_NAME, BINDING);
    Ok(())
}
```
