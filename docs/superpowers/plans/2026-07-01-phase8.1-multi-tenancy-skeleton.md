# Phase 8.1 — 多租户骨架（Skeleton）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地多租户骨架层 —— Tenant 实体表 + `iam_users` 加 `tenant_id` + JWT `tid` claim + `TenantScope` extractor + `digua_common-db` `WithTenantScope` helper + `iam.tenant.created` 事件 + 自助注册接口 `POST /iam/tenants`，建立后续 8.2 表迁移与 8.3 全面贯通的入口。

**Architecture:** 共享 MySQL `superpowers` 库 + 业务表加 `tenant_id` 列；一用户 = 一租户；JWT claim `tid: i64` 为唯一 tenant 来源；`iam_users.tenant_id` 由迁移种子 default=1（兼容期）。本期仅扩 `iam_users` 一张表作为穿透样板，其他业务表 schema 改造延后到 Phase 8.2。

**Tech Stack:** Rust 2021 / axum 0.8 / sqlx (MySQL) / jwt-simple (RS256) / lapin (RabbitMQ) / digua_common-event outbox / testcontainers.

## Global Constraints

- 所有 iam-service 业务表前缀 `iam_`（contracts/db-conventions.md，CI gate `scripts/check-db-naming.js`）。
- iam-service 仅 MySQL 方言（无 sqlite 迁移）。
- `tenant_id` 类型 `BIGINT UNSIGNED`，自增；`id=1` 永久保留给 `default` tenant。
- envelope.tenant_id 字段类型保持 `Option<String>`（producer `i64.to_string()`，consumer `parse::<i64>().unwrap_or(1)`）—— 不改 schema 避免存量 outbox/archive 漂移。
- JWT claim 名 = `tid`（数字 i64），non-empty token 缺 `tid` 时 `Principal.tenant_id = 1`（8.1 兼容期，8.3 收紧为 401）。
- 注册接口 `POST /iam/tenants` 公开（无 auth），IP-based rate limit 10 次/小时（沿用 `digua_common-ratelimit`）。
- TDD：每个 task 先写 failing test → 实现 → pass → commit。
- 本期 e2e 隔离验证仅覆盖 `iam_users`；roles/audit/announcements 等仍跨租户可见 —— 文档显式说明，不视为缺陷。
- 不在 `digua_common-event` 加 `with_tenant_from_principal` —— 用 callsite `.with_tenant_id(p.tenant_id.to_string())` 避免基础 lib 反向依赖 jwt-ctx。

```rust
use axum::extract::FromRequestParts;
use axum::http::request::Parts;
use axum::http::StatusCode;
use crate::Principal;

#[derive(Debug, Clone, Copy)]
pub struct TenantScope(pub i64);

impl<S: Send + Sync> FromRequestParts<S> for TenantScope {
    type Rejection = StatusCode;
    async fn from_request_parts(parts: &mut Parts, state: &S) -> Result<Self, Self::Rejection> {
        let p = Principal::from_request_parts(parts, state).await?;
        Ok(TenantScope(p.tenant_id))
    }
}
```

**Interfaces:**

- Produces: `issue_access_token(user_id, username, tenant_id: i64, roles, permissions) -> Result<String, IamError>`；JWT custom claim `tid: i64`

- [ ] **Step 1: 改 token_svc.rs**

```rust
// services/iam-service/src/service/token_svc.rs
pub fn issue_access_token(
    &self,
    user_id: &str,
    username: &str,
    tenant_id: i64,
    roles: Vec<String>,
    permissions: Vec<String>,
) -> Result<String, IamError> {
    let ttl_sec = self.state.config.jwt.access_token_ttl_minutes * 60;
    let now = Self::now();
    let mut claims: JWTClaims<HashMap<String, serde_json::Value>> = JWTClaims::new();
    claims.subject = Some(user_id.to_string());
    claims.issuer = Some("superpowers-token-service".to_string());
    claims.issued_at = Some(now);
    claims.jwt_id = Some(uuid::Uuid::new_v4().to_string());
    claims.expires_at = Some(now + Duration::from_secs(ttl_sec as u64));

    let mut custom = HashMap::new();
    custom.insert("username".to_string(), serde_json::Value::String(username.to_string()));
    custom.insert("tid".to_string(), serde_json::Value::Number(serde_json::Number::from(tenant_id)));
    custom.insert("roles".to_string(), serde_json::Value::Array(roles.into_iter().map(serde_json::Value::String).collect()));
    custom.insert("permissions".to_string(), serde_json::Value::Array(permissions.into_iter().map(serde_json::Value::String).collect()));
    claims.custom = custom;

    let token = self.key_pair.sign(claims).map_err(|e| IamError::Jwt(e.to_string()))?;
    Ok(token)
}
```

```rust
// services/iam-service/src/service/tenant_svc.rs
use crate::{state::AppState, dto::{CreateTenantRequest, CreateTenantResponse}, error::IamError};
use digua_common_event::{Envelope, OutboxRepo, events::IamTenantCreated};
use sqlx::Acquire;
use uuid::Uuid;

pub struct TenantService { state: AppState }

impl TenantService {
    pub fn new(state: AppState) -> Self { Self { state } }

    pub async fn register(&self, req: CreateTenantRequest) -> Result<CreateTenantResponse, IamError> {
        let mut tx = self.state.db.begin().await.map_err(IamError::from)?;

        // 1. INSERT iam_tenants
        let now = chrono::Utc::now();
        let tenant_res = sqlx::query(
            "INSERT INTO iam_tenants (slug, display_name, status, created_at, updated_at) VALUES (?, ?, 'active', ?, ?)"
        )
        .bind(&req.tenant_slug)
        .bind(&req.display_name)
        .bind(now)
        .bind(now)
        .execute(&mut *tx)
        .await
        .map_err(|e| match e.as_database_error().and_then(|db| db.code()).map(|c| c.into_owned()).as_deref() {
            Some("23000") => IamError::DuplicateTenant,  // MySQL duplicate key
            _ => IamError::from(e),
        })?;
        let tenant_id = tenant_res.last_insert_id() as i64;

        // 2. INSERT iam_users (admin)
        let admin_id = Uuid::new_v4().to_string();
        let password_hash = bcrypt::hash(&req.admin_password, bcrypt::DEFAULT_COST)
            .map_err(|e| IamError::Internal(e.to_string()))?;
        sqlx::query(
            "INSERT INTO iam_users (id, tenant_id, username, nickname, password_hash, email, status, created_at, updated_at) \
             VALUES (?, ?, ?, ?, ?, ?, 'active', ?, ?)"
        )
        .bind(&admin_id)
        .bind(tenant_id)
        .bind(&req.admin_username)
        .bind(&req.admin_username)  // nickname = username 默认
        .bind(&password_hash)
        .bind(&req.admin_email)
        .bind(now)
        .bind(now)
        .execute(&mut *tx)
        .await?;

        // 3. bind admin to global tenant_admin role（V003 之外的 seed，需要 Task 1 补；若 V001 已有，跳过）
        sqlx::query(
            "INSERT INTO iam_user_roles (user_id, role_id) \
             SELECT ?, id FROM iam_roles WHERE code = 'tenant_admin' LIMIT 1"
        )
        .bind(&admin_id)
        .execute(&mut *tx)
        .await?;

        // 4. enqueue iam.tenant.created
        let payload = IamTenantCreated {
            tenant_id: tenant_id.to_string(),
            slug: req.tenant_slug.clone(),
            display_name: req.display_name.clone(),
            admin_user_id: admin_id.clone(),
        };
        let mut envelope = Envelope::new("iam-service", payload)
            .with_tenant_id(tenant_id.to_string());
        self.state.outbox_repo.enqueue(&mut tx, &mut envelope).await
            .map_err(|e| IamError::Internal(e.to_string()))?;

        tx.commit().await.map_err(IamError::from)?;

        Ok(CreateTenantResponse { tenant_id, admin_user_id: admin_id })
    }
}
```

```rust
// services/iam-service/src/routes/tenants.rs
use axum::{Router, routing::post, extract::{State, Json}, http::StatusCode, Json as AxumJson};
use validator::Validate;
use crate::{state::AppState, dto::{CreateTenantRequest, CreateTenantResponse}, service::TenantService, error::IamError};

pub fn routes(state: AppState) -> Router {
    Router::new()
        .route("/iam/tenants", post(register_tenant))
        .with_state(state)
}

#[utoipa::path(
    post,
    path = "/iam/tenants",
    request_body = CreateTenantRequest,
    responses(
        (status = 201, body = CreateTenantResponse),
        (status = 400, description = "invalid request"),
        (status = 409, description = "tenant slug already exists"),
    ),
    tag = "tenants"
)]
pub async fn register_tenant(
    State(state): State<AppState>,
    Json(req): Json<CreateTenantRequest>,
) -> Result<(StatusCode, AxumJson<CreateTenantResponse>), (StatusCode, &'static str)> {
    req.validate().map_err(|_| (StatusCode::BAD_REQUEST, "invalid request"))?;
    let svc = TenantService::new(state);
    let resp = svc.register(req).await.map_err(|e| {
        tracing::error!("register tenant failed: {:?}", e);
        match e {
            IamError::DuplicateTenant => (StatusCode::CONFLICT, "tenant slug already exists"),
            _ => (StatusCode::INTERNAL_SERVER_ERROR, "internal error"),
        }
    })?;
    Ok((StatusCode::CREATED, AxumJson(resp)))
}
```
