# Phase 4.2 — `iam.login.failed` + 简易风控消费者 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iam-service 在四种登录失败路径发出事务性 `iam.login.failed` 事件；audit-service 自动审计落库（零改动），并新增独立风控 consumer 按 username/IP 滑动窗口计数 + 越线 WARN 告警 + Prometheus 计数器。

**Architecture:** 复用 Phase 4 事务性 outbox（iam 生产端）+ RabbitMQ topic exchange + Phase 4.1 consumer 重连模式。事件契约由 `contracts/events.yaml` codegen 出 Rust struct。审计落库走现有 `iam.#` 绑定零改动；风控走新独立队列 `audit.login-risk`，Redis INCR+EXPIRE 实现滑动窗口。

**Tech Stack:** Rust / axum / sqlx(MySQL) / lapin(RabbitMQ) / redis(ConnectionManager) / prometheus / Node codegen / testcontainers。

**Spec:** `docs/superpowers/specs/2026-06-27-phase4.2-login-failed-risk-design.md`

## Global Constraints

- 所有新表/列前缀规范：iam 服务 `iam_`，audit 服务 `audit_`（本计划不新建表）。CI 门禁：`node scripts/check-db-naming.js`。
- 事件契约**只改 `contracts/events.yaml`**，Rust 代码由 `node scripts/contracts-gen.js` 生成；`libs/common-event/src/events.rs` 与 `routing_keys.rs` 标注 `DO NOT EDIT MANUALLY`，禁止手改。
- 契约同步门禁：`node scripts/contracts-gen.js --check` 必须 in-sync。
- 风控计数**不做 event_id 幂等去重**（有意为之，spec §4.3）。
- 风控 handler 遇 Redis 错误**照常 ack**（吞错返回 Ok），不得 nack 进 DLQ。
- `iam_login_logs` 有 `FOREIGN KEY (user_id) REFERENCES iam_users(id)`：`user_not_found` 路径 `user_id` 必须绑定 SQL NULL（`Option::None`），**禁止**空字符串。
- Rust 在 Docker builder 容器内构建/测试，命令见各 Task（musl target）。

```rust
async fn record_login_failure(
    &self,
    username: &str,
    user_id: Option<&str>,
    ip: &str,
    user_agent: &str,
    reason: &str,
) -> Result<(), IamError> {
    let mut tx = self.state.db.begin().await?;
    sqlx::query(
        "INSERT INTO iam_login_logs (id, user_id, username, ip_address, user_agent, \
         login_type, success, error_message, created_at) \
         VALUES (?, ?, ?, ?, ?, 'password', false, ?, NOW())",
    )
    .bind(nanoid!())
    .bind(user_id)
    .bind(username)
    .bind(ip)
    .bind(user_agent)
    .bind(reason)
    .execute(&mut *tx)
    .await?;

    let envelope = Envelope::new(
        "iam-service",
        IamLoginFailed {
            username: username.to_string(),
            user_id: user_id.map(|s| s.to_string()),
            ip: ip.to_string(),
            user_agent: Some(user_agent.to_string()),
            reason: reason.to_string(),
        },
    );
    common_event::MySqlOutboxRepo::new(self.state.db.clone())
        .enqueue(&mut tx, &envelope)
        .await
        .map_err(|e| IamError::Internal(e.to_string()))?;
    tx.commit().await?;
    Ok(())
}
```

```rust
use redis::aio::ConnectionManager;
use redis::AsyncCommands;

#[derive(Clone)]
pub struct RedisCli {
    pub conn: ConnectionManager,
}

impl RedisCli {
    pub async fn connect(url: &str) -> anyhow::Result<Self> {
        let client = redis::Client::open(url)?;
        let conn = ConnectionManager::new(client).await?;
        Ok(Self { conn })
    }

    /// INCR key; on first hit (==1) set EXPIRE window_secs. Returns the new count.
    /// Sliding-window semantics: the key lives for window_secs from its first hit.
    pub async fn incr_with_window(&self, key: &str, window_secs: usize) -> anyhow::Result<i64> {
        let mut c = self.conn.clone();
        let n: i64 = c.incr(key, 1).await?;
        if n == 1 {
            let _: () = c.expire(key, window_secs as i64).await?;
        }
        Ok(n)
    }
}
```

> 注：`redis 0.27` 的 `expire` 第二参为 `i64`（秒）。若编译报参数类型，按编译器提示调整为 `expire(key, window_secs as usize)`，以本仓 redis 版本签名为准。

- [ ] **Step 2: 写 `risk.rs`（含越线纯函数 + 单测先行）**

```rust
//! 风控 consumer：独立订阅 iam.login.failed，按 username/IP 滑动窗口计数，
//! 越线时打 WARN 日志 + 递增 Prometheus 计数器。仅计数+告警，不锁号、不通知。
//!
//! Redis 出错时照常处理（吞错返回 Ok）——风控是尽力而为，不能因 Redis 抖动
//! 把消息卡进 DLQ。计数不做 event_id 幂等去重（至少一次投递下偶发偏高可接受）。

use std::time::Duration;

use common_event::events::IamLoginFailed;
use common_event::{Consumer, Envelope, HandlerError, RabbitMqConsumer};
use prometheus::{register_int_counter_vec, IntCounterVec};
use std::sync::OnceLock;
use tracing::{info, warn};

use crate::redis_cli::RedisCli;

const QUEUE_NAME: &str = "audit.login-risk";
const BINDING: &str = "iam.login.failed";

static LOGIN_RISK_ALERTS: OnceLock<IntCounterVec> = OnceLock::new();

pub fn init_metrics() {
    let counter = register_int_counter_vec!(
        "login_risk_alerts_total",
        "Total login-failure risk threshold crossings",
        &["dimension"]
    )
    .expect("register_int_counter_vec login_risk_alerts_total failed");
    LOGIN_RISK_ALERTS.get_or_init(|| counter);
}

#[derive(Debug, Clone, Copy)]
pub struct RiskOptions {
    pub threshold: i64,
    pub window_secs: usize,
}

/// 窗口内只在「恰好等于阈值」那一次告警，避免刷屏。
fn crosses_threshold(count: i64, threshold: i64) -> bool {
    count == threshold
}

async fn count_dimension(
    redis: &RedisCli,
    dimension: &str,
    key_value: &str,
    opts: &RiskOptions,
) {
    let key = format!("audit:loginfail:{dimension}:{key_value}");
    match redis.incr_with_window(&key, opts.window_secs).await {
        Ok(n) => {
            if crosses_threshold(n, opts.threshold) {
                warn!(
                    dimension,
                    key_value,
                    count = n,
                    window_secs = opts.window_secs,
                    "login failure threshold exceeded"
                );
                if let Some(c) = LOGIN_RISK_ALERTS.get() {
                    c.with_label_values(&[dimension]).inc();
                }
            }
        }
        Err(e) => {
            warn!(error = %e, dimension, key_value, "risk counter redis error (non-fatal, acking)");
        }
    }
}

async fn handle(redis: &RedisCli, env: &Envelope<IamLoginFailed>, opts: &RiskOptions) -> Result<(), HandlerError> {
    let p = &env.payload;
    if !p.username.is_empty() {
        count_dimension(redis, "user", &p.username, opts).await;
    }
    if !p.ip.is_empty() {
        count_dimension(redis, "ip", &p.ip, opts).await;
    }
    Ok(())
}

pub async fn run(redis: RedisCli, event_bus_url: String, opts: RiskOptions) -> anyhow::Result<()> {
    let backoff = Duration::from_secs(5);
    loop {
        match try_subscribe(redis.clone(), &event_bus_url, opts).await {
            Ok(()) => tokio::time::sleep(Duration::from_secs(30)).await,
            Err(e) => {
                warn!(error = %e, "risk consumer subscribe failed, retry in 5s");
                tokio::time::sleep(backoff).await;
            }
        }
    }
}

async fn try_subscribe(redis: RedisCli, event_bus_url: &str, opts: RiskOptions) -> anyhow::Result<()> {
    let consumer = RabbitMqConsumer::new(event_bus_url).await?;
    consumer
        .subscribe::<IamLoginFailed, _, _>(
            QUEUE_NAME,
            &[BINDING],
            move |env: Envelope<IamLoginFailed>| {
                let redis = redis.clone();
                async move { handle(&redis, &env, &opts).await }
            },
        )
        .await?;
    info!("risk consumer subscribed to {} ({})", QUEUE_NAME, BINDING);
    Ok(())
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn alerts_only_at_threshold() {
        assert!(!crosses_threshold(1, 5));
        assert!(!crosses_threshold(4, 5));
        assert!(crosses_threshold(5, 5));
        assert!(!crosses_threshold(6, 5)); // 不重复告警
    }
}
```

> 注：`RiskOptions` 派生 `Copy`，所以可按值 move 进闭包多次（重连循环每次 `try_subscribe(opts)`）。`handle`/`count_dimension` 内任何 Redis 错误都不向上传播为 `Err`，保证 ack。

```rust
        let redis_url = config.redis_url.clone();
        tokio::spawn(async move {
            match audit_service::redis_cli::RedisCli::connect(&redis_url).await {
                Ok(redis) => {
                    if let Err(e) = audit_service::risk::run(redis, event_bus_url, opts).await {
                        warn!("risk consumer exited: {}", e);
                    }
                }
                Err(e) => warn!("risk consumer: redis connect failed: {}", e),
            }
        });
    }
```

> 注：原 consumer spawn 块里 `event_bus_url` 被 move。本块重新从 env 读取，互不影响。`config` 在此处仍可读（`create_state(pool)` 在其后调用，`config` 未被 move）。如顺序冲突，把本块上移到 `create_state` 之前即可。

```rust
//! 风控 consumer 集成测试：发布 threshold 条 iam.login.failed（同一 username），
//! 断言 Redis 计数到达 threshold（越线告警是副作用，靠计数验证窗口逻辑）。
use std::time::Duration;

use audit_service::redis_cli::RedisCli;
use audit_service::risk::{self, RiskOptions};
use common_event::events::IamLoginFailed;
use common_event::{Envelope, Publisher, RabbitMqPublisher};
use testcontainers_modules::{rabbitmq::RabbitMq, redis::Redis, testcontainers::runners::AsyncRunner};

#[tokio::test]
async fn risk_counter_reaches_threshold() {
    let rabbit = RabbitMq::default().start().await.unwrap();
    let amqp_port = rabbit.get_host_port_ipv4(5672).await.unwrap();
    let amqp_host = rabbit.get_host().await.unwrap();
    let amqp_url = format!("amqp://guest:guest@{amqp_host}:{amqp_port}/%2f");

    let redis_c = Redis::default().start().await.unwrap();
    let redis_port = redis_c.get_host_port_ipv4(6379).await.unwrap();
    let redis_host = redis_c.get_host().await.unwrap();
    let redis_url = format!("redis://{redis_host}:{redis_port}");

    let redis = RedisCli::connect(&redis_url).await.unwrap();

    let opts = RiskOptions { threshold: 5, window_secs: 300 };
    {
        let redis = redis.clone();
        let url = amqp_url.clone();
        tokio::spawn(async move { let _ = risk::run(redis, url, opts).await; });
    }
    // 等 consumer 订阅就绪
    tokio::time::sleep(Duration::from_secs(2)).await;

    // 连接 publisher（AMQP listener 可能晚于端口开放，重试）
    let publisher = {
        let mut last = None;
        for _ in 0..20 {
            match RabbitMqPublisher::new(&amqp_url, "events").await {
                Ok(p) => { last = Some(p); break; }
                Err(_) => tokio::time::sleep(Duration::from_millis(500)).await,
            }
        }
        last.expect("publisher connect")
    };

    for _ in 0..5 {
        let env = Envelope::new("test", IamLoginFailed {
            username: "attacker".into(),
            user_id: None,
            ip: "9.9.9.9".into(),
            user_agent: None,
            reason: "bad_password".into(),
        });
        publisher.publish(&env).await.unwrap();
    }

    // 轮询 Redis 直到计数到 5（或超时）
    let mut conn = redis.conn.clone();
    use redis::AsyncCommands;
    let mut count: i64 = 0;
    for _ in 0..40 {
        count = conn.get::<_, Option<i64>>("audit:loginfail:user:attacker").await.unwrap().unwrap_or(0);
        if count >= 5 { break; }
        tokio::time::sleep(Duration::from_millis(250)).await;
    }
    assert_eq!(count, 5, "expected risk counter to reach threshold");
}
```
