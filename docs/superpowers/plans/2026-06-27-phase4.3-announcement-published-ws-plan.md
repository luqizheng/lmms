# Phase 4.3 — `notification.announcement.published` + 事件驱动 WebSocket 广播 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** notification-service 发布公告时，在同一事务里解析 user-scope 接收人、插 delivery、翻 published、经 outbox enqueue `notification.announcement.published`；独立 `ntf-outbox-publisher` 发到 RabbitMQ；每个副本各自 exclusive 队列消费并对本地连接的命中用户推 `WsOut::New`，从而修复多副本 WS 广播。

**Architecture:** 复用 Phase 4 事务性 outbox（`common_event::MySqlOutboxRepo::with_table`）+ iam 的 `outbox-publisher` 生产级 reconnect 二进制模式 + Phase 4.1 consumer reconnect 模式。新增 per-replica ephemeral 队列扇出（每副本一份 copy）。notification-service 首次成为事件生产者。

**Tech Stack:** Rust / axum(ws) / sqlx(MySQL) / lapin(RabbitMQ) / Node codegen / testcontainers。

**Spec:** `docs/superpowers/specs/2026-06-27-phase4.3-announcement-published-ws-design.md`

## Global Constraints

- 事件契约**只改 `contracts/events.yaml`**，Rust 由 `node scripts/contracts-gen.js` 生成；`libs/common-event/src/events.rs` 与 `routing_keys.rs` 标 `DO NOT EDIT MANUALLY`，禁止手改。契约同步门禁 `node scripts/contracts-gen.js --check` 必须 in-sync。
- 所有 notification 表前缀 `ntf_`；CI 门禁 `node scripts/check-db-naming.js` 必须 PASS。
- `ntf_outbox_events` 的列定义**必须逐列等于** `iam_outbox_events`（仅改前缀/索引名），因为 `MySqlOutboxRepo` 的 SQL 写死列名 `event_id/event_type/routing_key/envelope_json/created_at/published_at`（见 §Task 2 验收）。
- 发布的并发正确性：`publish_announcement` 第 1 步必须 `SELECT ... FOR UPDATE` 锁公告行 + 状态守卫，仅未发布时继续（防 scheduler 与 REST 并发重复 enqueue）。【评审 3A】
- live WS 是 **best-effort**：consumer handler 遇错照常返回（不 nack 进 DLQ 概念，这里 ephemeral 无 DLX）；无 event_id 幂等去重（前端按 id 去重）。durable 兜底是 delivery 行 + `list_for_user` reload。【评审 2A/4.3】
- 生产端 `publish_announcement` **不**直接 `hub.publish`；推送统一由 consumer 完成（避免双推）。【spec §3.2】
- Rust 在 Docker musl builder 容器内构建/测试；测试命令见各 Task（testcontainers 需挂 `/var/run/docker.sock`）。

## 数据流（ASCII，供 spec/实现内联图注参照）

```
publish (REST publish 或 scheduler tick)
        │
        ▼
Db::publish_announcement(ann_id)  ── ONE TX ──────────────────────────┐
  1. SELECT ... FOR UPDATE 锁行 + 状态守卫(仅未发布继续，否则幂等返回)  │ 【3A】
  2. SELECT user-scope recipients → user_ids (role/dept 仅 warn 跳过)  │
  3. INSERT IGNORE deliveries (每 user_id)                            │
  4. UPDATE status=published                                          │
  5. enqueue → ntf_outbox_events (MySqlOutboxRepo::with_table)        │
  COMMIT ────────────────────────────────────────────────────────────┘
        │
        ▼
ntf-outbox-publisher (独立进程, 轮询 ntf_outbox_events) ──▶ events topic exchange
                                              │ rk = notification.announcement.published
        ┌─────────────────────────────────────┼──────────────────────────┐
        ▼ (broker 扇出, 每副本一份 copy)        ▼
  replicaA ephemeral queue              replicaB ephemeral queue
  (exclusive/auto_delete/非持久,         (同左)
   启动即声明绑定) 【2A】
        │ consume                              │ consume
        ▼                                      ▼
  for uid in user_ids: hub.publish(uid, New)  (同左)
        │ (仅对本副本有本地 WS 连接的 uid 实际送达)
        ▼
   browser WS
```

- [ ] **Step 2: 实现 `publish_announcement`（带 ASCII 图注）**【评审 3A + 5A】

在 `impl Db` 内新增。**图注必须包含**（5 步事务管线 + 两调用方 + 事件去向，见本计划顶部数据流图）：

```rust
/// 公告发布的统一事务管线（REST publish + scheduler 共用）。
///
/// ```text
/// publish_announcement(ann_id)  ── ONE TX ──
///   1. SELECT ... FOR UPDATE 锁行；非未发布状态 → 幂等返回 Ok(vec![])
///   2. SELECT scope_type='user' recipients → user_ids（role/dept 仅 warn 跳过）
///   3. INSERT IGNORE deliveries（每 user_id）
///   4. UPDATE status='published'
///   5. enqueue NotificationAnnouncementPublished → ntf_outbox_events
///   COMMIT
/// ```
/// 不在此处 hub.publish —— 推送统一由 announcement consumer 完成（避免双推）。
pub async fn publish_announcement(&self, ann_id: u64) -> AppResult<Vec<String>> {
    let mut tx = self.pool.begin().await?;

    // 1. 锁行 + 状态守卫
    let row: Option<(String, String, i8, i8)> = sqlx::query_as(
        "SELECT title, status, pinned, popover FROM ntf_announcements WHERE id=? FOR UPDATE",
    )
    .bind(ann_id)
    .fetch_optional(&mut *tx)
    .await?;
    let (title, status, pinned, popover) = match row {
        Some(r) => r,
        None => {
            tx.commit().await?;
            return Ok(vec![]);
        }
    };
    if status == "published" || status == "revoked" {
        tx.commit().await?;
        return Ok(vec![]);
    }

    // 2. user-scope 接收人（role/dept 跳过 — follow-up 4.3-fu2）
    let scope_rows: Vec<(String, String)> = sqlx::query_as(
        "SELECT scope_type, scope_id FROM ntf_announcement_recipients WHERE announcement_id=?",
    )
    .bind(ann_id)
    .fetch_all(&mut *tx)
    .await?;
    let mut user_ids: Vec<String> = Vec::new();
    let mut skipped_non_user = 0usize;
    for (st, sid) in scope_rows {
        if st == "user" {
            user_ids.push(sid);
        } else {
            skipped_non_user += 1;
        }
    }
    if skipped_non_user > 0 {
        warn!(ann_id, skipped_non_user, "role/dept recipient scopes skipped (user-scope only; see 4.3-fu2)");
    }

    // 3. deliveries
    for uid in &user_ids {
        sqlx::query(
            "INSERT IGNORE INTO ntf_announcement_deliveries (announcement_id, user_id, delivered_at) VALUES (?,?,NOW())",
        )
        .bind(ann_id)
        .bind(uid)
        .execute(&mut *tx)
        .await?;
    }

    // 4. status
    sqlx::query("UPDATE ntf_announcements SET status='published' WHERE id=?")
        .bind(ann_id)
        .execute(&mut *tx)
        .await?;

    // 5. enqueue
    let envelope = Envelope::new(
        "notification-service",
        NotificationAnnouncementPublished {
            announcement_id: ann_id as i64,
            title,
            pinned: pinned != 0,
            popover: popover != 0,
            user_ids: serde_json::json!(user_ids),
        },
    );
    MySqlOutboxRepo::with_table(self.pool.clone(), "ntf_outbox_events")
        .enqueue(&mut tx, &envelope)
        .await
        .map_err(|e| AppError::from(anyhow::anyhow!("outbox enqueue: {e}")))?;

    tx.commit().await?;
    Ok(user_ids)
}
```

> 注：`AppError` 的构造按 `error.rs` 现有变体调整（若无 `From<anyhow::Error>`，用现有 `AppError::Internal`/等价变体把 `OutboxError` 字符串包进去）。实现者以 `error.rs` 实际 API 为准；目标是 enqueue 失败映射为 `AppError` 并触发事务回滚（`tx` drop 即回滚）。

**Interfaces:**

- [ ] **Step 1: 定义 `SubscribeOptions` + 重构 `subscribe_inner`**【评审 1B】

在 `consumer.rs`：
```rust
#[derive(Debug, Clone)]
pub struct SubscribeOptions {
    pub durable: bool,
    pub exclusive: bool,
    pub auto_delete: bool,
    pub with_dlx: bool,
    pub consumer_tag: String,
}
```
把现有 `subscribe` 的 channel/exchange/queue_declare/bind/consume/spawn 主体抽成私有 `async fn subscribe_inner<P,H,Fut>(&self, queue: &str, bindings: &[&str], opts: SubscribeOptions, handler: H) -> Result<(), ConsumeError>`：
- `queue_declare` 用 `QueueDeclareOptions { durable: opts.durable, exclusive: opts.exclusive, auto_delete: opts.auto_delete, ..Default::default() }`。
- DLX arg 仅当 `opts.with_dlx` 时插入 `x-dead-letter-exchange=events.dlx`。
- `basic_consume` 的 consumer tag 用 `opts.consumer_tag`（**取代写死的 `"audit-service"`**）。
- server-named queue：当 `queue` 为 `""` 时，`queue_declare("")` 让 broker 命名；绑定时用 `queue_declare` 返回的实际队列名（lapin 的 `queue_declare` 返回 `Queue`，取 `.name()`）。

- [ ] **Step 2: 两个 public 方法变薄封装**

```rust
async fn subscribe<P,H,Fut>(&self, queue: &str, bindings: &[&str], handler: H) -> Result<(), ConsumeError> {
    self.subscribe_inner(queue, bindings, SubscribeOptions {
        durable: true, exclusive: false, auto_delete: false, with_dlx: true,
        consumer_tag: format!("{}-{}", queue, uuid::Uuid::new_v4()),
    }, handler).await
}

async fn subscribe_ephemeral<P,H,Fut>(&self, bindings: &[&str], handler: H) -> Result<(), ConsumeError> {
    self.subscribe_inner("", bindings, SubscribeOptions {
        durable: false, exclusive: true, auto_delete: true, with_dlx: false,
        consumer_tag: format!("ephemeral-{}", uuid::Uuid::new_v4()),
    }, handler).await
}
```

pub mod announcement_events;

const ANN_BINDING: &str = "notification.announcement.published";

pub async fn announcement_run(hub: WsHub, event_bus_url: String) -> anyhow::Result<()> {
    let backoff = std::time::Duration::from_secs(5);
    loop {
        match ann_try_subscribe(hub.clone(), &event_bus_url).await {
            Ok(()) => tokio::time::sleep(std::time::Duration::from_secs(30)).await,
            Err(e) => {
                warn!(error = %e, "announcement consumer subscribe failed, retry in 5s");
                tokio::time::sleep(backoff).await;
            }
        }
    }
}

async fn ann_try_subscribe(hub: WsHub, event_bus_url: &str) -> anyhow::Result<()> {
    let consumer = RabbitMqConsumer::new(event_bus_url).await?;
    consumer
        .subscribe_ephemeral::<NotificationAnnouncementPublished, _, _>(
            &[ANN_BINDING],
            move |env: Envelope<NotificationAnnouncementPublished>| {
                let hub = hub.clone();
                async move { announcement_events::handle(&hub, &env).await }
            },
        )
        .await?;
    info!("announcement consumer subscribed (ephemeral) to {}", ANN_BINDING);
    Ok(())
}

```rust
//! Independent outbox publisher for notification-service (Phase 4.3).
//! Polls `ntf_outbox_events` and publishes to RabbitMQ. Same image as
//! notification-service, different CMD. Mirrors iam-service/src/bin/outbox_publisher.rs.
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use std::time::Duration;

use common_event::{MySqlOutboxRepo, OutboxRepo, Publisher, RabbitMqPublisher};
use sqlx::mysql::MySqlPoolOptions;
use tracing::{info, warn};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    common_telemetry::init_tracing("ntf-outbox-publisher");
    info!("ntf-outbox-publisher starting");

    let db_url = std::env::var("DATABASE_URL").unwrap_or_else(|_| {
        let host = std::env::var("DATABASE_HOST").unwrap_or_else(|_| "127.0.0.1".into());
        let port = std::env::var("DATABASE_PORT").unwrap_or_else(|_| "3306".into());
        let user = std::env::var("DATABASE_USER").unwrap_or_else(|_| "root".into());
        let pass = std::env::var("DATABASE_PASSWORD").unwrap_or_else(|_| "rootpass".into());
        let name = std::env::var("DATABASE_NAME").unwrap_or_else(|_| "superpowers".into());
        format!("mysql://{user}:{pass}@{host}:{port}/{name}")
    });
    let event_bus_url = std::env::var("EVENT_BUS_URL")
        .unwrap_or_else(|_| "amqp://guest:guest@localhost:5672/%2f".to_string());
    let exchange = std::env::var("EVENT_BUS_EXCHANGE").unwrap_or_else(|_| "events".to_string());
    let poll_ms: u64 = std::env::var("OUTBOX_POLL_INTERVAL_MS").ok().and_then(|s| s.parse().ok()).unwrap_or(1000);
    let batch_size: u32 = std::env::var("OUTBOX_BATCH_SIZE").ok().and_then(|s| s.parse().ok()).unwrap_or(100);

    let pool = MySqlPoolOptions::new()
        .max_connections(8)
        .acquire_timeout(Duration::from_secs(5))
        .connect(&db_url)
        .await?;
    let repo = MySqlOutboxRepo::with_table(pool, "ntf_outbox_events");

    let shutdown = Arc::new(AtomicBool::new(false));
    {
        let shutdown = shutdown.clone();
        tokio::spawn(async move {
            #[cfg(unix)]
            {
                use tokio::signal::unix::{signal, SignalKind};
                let mut term = signal(SignalKind::terminate()).expect("install SIGTERM");
                tokio::select! { _ = tokio::signal::ctrl_c() => {}, _ = term.recv() => {} }
            }
            #[cfg(not(unix))]
            { let _ = tokio::signal::ctrl_c().await; }
            warn!("shutdown signal received, finishing current batch then exiting");
            shutdown.store(true, Ordering::SeqCst);
        });
    }

    info!(poll_ms, batch_size, "ntf outbox publisher ready");
    let poll_interval = Duration::from_millis(poll_ms);
    let mut publisher: Option<RabbitMqPublisher> = None;

    while !shutdown.load(Ordering::SeqCst) {
        if publisher.is_none() {
            match RabbitMqPublisher::new(&event_bus_url, &exchange).await {
                Ok(p) => { info!("connected to RabbitMQ"); publisher = Some(p); }
                Err(e) => { warn!(error = %e, "connect rabbitmq failed, retry"); tokio::time::sleep(poll_interval).await; continue; }
            }
        }
        let pub_ref = publisher.as_ref().unwrap();
        let batch = match repo.claim_batch(batch_size).await {
            Ok(b) => b,
            Err(e) => { warn!(error = %e, "claim_batch failed, retry"); tokio::time::sleep(poll_interval).await; continue; }
        };
        if batch.is_empty() { tokio::time::sleep(poll_interval).await; continue; }

        let mut published_ids = Vec::with_capacity(batch.len());
        let mut broker_failed = false;
        for row in &batch {
            let body = match serde_json::to_vec(&row.envelope_json) {
                Ok(b) => b,
                Err(e) => { warn!(error = %e, id = row.id, "skip unserializable row"); continue; }
            };
            match pub_ref.publish_raw(&row.routing_key, &row.event_id.to_string(), &body).await {
                Ok(()) => published_ids.push(row.id),
                Err(e) => { warn!(error = %e, id = row.id, "publish failed, reconnect"); broker_failed = true; break; }
            }
        }
        if !published_ids.is_empty() {
            if let Err(e) = repo.mark_published(&published_ids).await {
                warn!(error = %e, "mark_published failed; rows will be reclaimed");
            } else {
                info!(published = published_ids.len(), "published ntf outbox batch");
            }
        }
        if broker_failed { publisher = None; tokio::time::sleep(poll_interval).await; }
    }
    info!("ntf outbox publisher exited cleanly");
    Ok(())
}
```
