# Phase 4.4-fu2 + 4.3-fu2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship (a) actor_id pass-through into `iam.permission.changed` events and (b) real role/dept recipient expansion in `notification-service::publish_announcement`, behind a tenant-isolated service-jwt IAM internal API.

**Architecture:** Two services, three logical layers. (1) iam-service gains 2 internal GET endpoints (by-role/by-dept) gated by a new `require_service_jwt` middleware that distinguishes service-jwt (`aud` claims `service`) from user-jwt. (2) iam write endpoints (5) thread `Principal.user_id` into service `actor_id: Option<&str>` and into `iam.permission.changed.actor_id`. (3) notification-service gains `IamMemberClient` using Phase 5-B's `ResilientClient`; `publish_announcement` splits into tx-out IAM fetch + tx-in deliveries + idempotent re-lock, eliminating the silent role/dept skip.

**Tech Stack:** Rust · axum · sqlx (MySQL) · redis (Phase 5-B context only) · lapin (Phase 4.x context) · `libs/digua_common-http::ResilientClient` · `libs/digua_common-error::AppError::external()` for cross-service failures · wiremock-rs for tests.

## Global Constraints

- **Service-jwt shape**: notification fetches a service-jwt from token-service. The token must contain `tid` (tenant_id, from 8.1) and `aud` containing the literal `service`. iam's `require_service_jwt` middleware rejects any JWT whose `aud` doesn't contain `service`, returning 401 with `{"code":"IAM_TOKEN_3004","message":"service token required"}`. User-jwts (no `service` aud) are NOT accepted on internal endpoints; admin tokens also NOT accepted.
- **Tenant isolation**: every internal query MUST `WHERE tenant_id = ?` with the value from `Principal.tenant_id`. No cross-tenant reads. `principal.user_id` for service-jwt is the literal string `service` (or empty) — not a real user_id; the field exists only to satisfy JWT parse.
- **Permission-changing writes** (4.4): every write MUST enqueue `iam.permission.changed` in the SAME business tx AND `stamp_perm_epochs` AFTER commit (best-effort), with `actor_id: Option<&str>` from the caller's Principal.
- **Cross-service failure semantics**: any non-2xx from IAM HTTP, or timeout, becomes `AppError::external("IAM_FAIL", msg)` (HTTP 502 to notification's caller). publish_announcement's tx-in step must NOT have run before the IAM fetch; if so, the row lock is released via early `tx.commit().await?` before fetch. Idempotent re-check inside the second tx protects against concurrent publishers.
- **`actor_id: Option<&str>` signatures**: service layer keeps `Option<&str>` even though all current handler call sites supply `Some(principal.user_id)` (or `None` for paths that don't yet have a Principal — currently zero). All callers must pass `Some(...)` once a Principal is available; the `Option` wrapper is for forward-compatibility with the (future) service-token-issued programmatic endpoint pattern.
- **No new migrations, no new tables, no contracts layer changes.**
- **Wiremock-rs version**: notification-service testcontainers + wiremock-rs coexistence is supported in Cargo.toml; if not, this task adds it.
- **`digua_common-http` dependency** in notification-service `Cargo.toml`: not yet declared; this plan adds it as a path dep.
- **`libs/digua_common-error::AppError::external(code, msg)` is the cross-service failure shape; it maps to HTTP 502. NO new error variant needed.**
- **No source mutation** to `services/notification-service/src/recipient_resolver.rs` (pure in-memory expansion, still useful for tests). The IAM-driven expand goes through `IamMemberClient::expand_scopes`.

//! Service-token gate for /iam/internal/* endpoints.
//!
//! Accepts only JWTs whose `aud` claim contains `"service"` and which carry a
//! `tid` claim. User tokens (admin / standard) are rejected on these routes.
//! Token signature is NOT verified (the api-gateway has already done so); we
//! decode the payload only.

use axum::{
    extract::State,
    http::{HeaderMap, StatusCode},
    middleware::Next,
    response::{IntoResponse, Response},
    Json,
};
use serde::Deserialize;
use serde_json::Value;

#[derive(Deserialize)]
struct JwtPayload {
    #[serde(default)]
    aud: Value,        // string or array
    #[serde(default)]
    tid: Value,
}

pub async fn require_service_jwt(
    headers: HeaderMap,
    req: Next,
) -> Result<Response, Response> {
    let auth = headers
        .get("Authorization")
        .and_then(|h| h.to_str().ok())
        .ok_or_else(unauthorized)?;
    let token = auth
        .strip_prefix("Bearer ")
        .ok_or_else(unauthorized)?;
    let parts: Vec<&str> = token.split('.').collect();
    if parts.len() != 3 {
        return Err(unauthorized());
    }
    let payload_bytes = base64_url_decode(parts[1])
        .map_err(|_| unauthorized())?;
    let p: JwtPayload = serde_json::from_slice(&payload_bytes)
        .map_err(|_| unauthorized())?;
    if !claim_has(&p.aud, "service") {
        return Err(unauthorized());
    }
    if !p.tid.is_i64() && !p.tid.is_u64() {
        return Err(unauthorized());
    }
    Ok(req.run().await)
}

fn claim_has(v: &Value, needle: &str) -> bool {
    match v {
        Value::String(s) => s == needle,
        Value::Array(arr) => arr.iter().any(|x| x.as_str() == Some(needle)),
        _ => false,
    }
}

fn base64_url_decode(s: &str) -> Result<Vec<u8>, ()> {
    use base64::engine::general_purpose::URL_SAFE_NO_PAD;
    use base64::Engine;
    URL_SAFE_NO_PAD.decode(s).map_err(|_| ())
}

fn unauthorized() -> Response {
    let body = serde_json::json!({
        "code": "IAM_TOKEN_3004",
        "message": "service token required",
    });
    (StatusCode::UNAUTHORIZED, Json(body)).into_response()
}

#[cfg(test)]
mod tests {
    use super::*;

    fn make_token(payload: &str) -> String {
        use base64::engine::general_purpose::URL_SAFE_NO_PAD;
        use base64::Engine;
        let header = URL_SAFE_NO_PAD.encode(b"{\"alg\":\"none\",\"typ\":\"JWT\"}");
        let body = URL_SAFE_NO_PAD.encode(payload.as_bytes());
        format!("{header}.{body}.signature")
    }

    #[test]
    fn admin_token_is_rejected() {
        let tok = make_token(r#"{"sub":"u-admin","tid":1,"roles":["admin"]}"#);
        assert_eq!(audience_contains(&tok, "service"), false);
        assert_eq!(tid_present(&tok), true);
    }

    #[test]
    fn service_token_array_aud_is_accepted() {
        let tok = make_token(r#"{"aud":["service","internal"],"tid":1}"#);
        assert_eq!(audience_contains(&tok, "service"), true);
    }

    #[test]
    fn service_token_string_aud_is_accepted() {
        let tok = make_token(r#"{"aud":"service","tid":1}"#);
        assert_eq!(audience_contains(&tok, "service"), true);

    fn audience_contains(tok: &str) -> bool {
        let parts: Vec<&str> = tok.split('.').collect();
        let bytes = URL_SAFE_NO_PAD.decode(parts[1]).unwrap();
        let p: serde_json::Value = serde_json::from_slice(&bytes).unwrap();

        let parts: Vec<&str> = tok.split('.').collect();
        let bytes = URL_SAFE_NO_PAD.decode(parts[1]).unwrap();
        let p: serde_json::Value = serde_json::from_slice(&bytes).unwrap();
        let v = &p.get("tid").cloned().unwrap_or(Value::Null);
        v.is_i64() || v.is_u64()
    }
}

    /// Internal: list user_ids belonging to a role. Tenant-scoped.
    /// Returns (items, total, truncated). `truncated=true` means items.len()==1000
    /// (the hard ceiling — caller must paginate if so).
    pub async fn list_by_role(
        &self,
        role_id: &str,
        page: u32,
        size: u32,
        tenant_id: i64,
    ) -> Result<(Vec<String>, i64, bool), IamError> {
        let size = size.clamp(1, 1000);
        let page = page.max(1);
        let offset = (page - 1) as i64 * size as i64;
        let limit = size as i64;
        let items: Vec<(String,)> = sqlx::query_as(
            "SELECT u.id
             FROM iam_users u
             JOIN iam_user_roles ur ON ur.user_id = u.id
             WHERE ur.role_id = ? AND u.deleted_at IS NULL AND u.tenant_id = ?
             ORDER BY u.id
             LIMIT ? OFFSET ?",
        )
        .bind(role_id).bind(tenant_id).bind(limit).bind(offset)
        .fetch_all(&self.state.db).await?;
        let total: (i64,) = sqlx::query_as(
            "SELECT COUNT(*) FROM iam_users u
             JOIN iam_user_roles ur ON ur.user_id = u.id
             WHERE ur.role_id = ? AND u.deleted_at IS NULL AND u.tenant_id = ?",
        )
        .bind(role_id).bind(tenant_id).fetch_one(&self.state.db).await?;
        let items: Vec<String> = items.into_iter().map(|(s,)| s).collect();
        let truncated = items.len() as u32 == 1000;
        Ok((items, total.0, truncated))
    }

    /// Internal: list user_ids belonging to a dept. Tenant-scoped.
    pub async fn list_by_dept(
        &self,
        dept_id: &str,
        page: u32,

    ) -> Result<(Vec<String>, i64, bool), IamError> {

        let limit = size as i64;
        let items: Vec<(String,)> = sqlx::query_as(

             WHERE u.org_unit_id = ? AND u.deleted_at IS NULL AND u.tenant_id = ?
             ORDER BY u.id
             LIMIT ? OFFSET ?",
        )

        )
        .bind(dept_id).bind(tenant_id).fetch_one(&self.state.db).await?;
        let items: Vec<String> = items.into_iter().map(|(s,)| s).collect();

fn mint_service_token(tid: i64) -> String {
    use base64::engine::general_purpose::URL_SAFE_NO_PAD;
    use base64::Engine;
    let header = URL_SAFE_NO_PAD.encode(b"{\"alg\":\"none\",\"typ\":\"JWT\"}");
    let payload = format!(r#"{{"aud":"service","tid":{tid}}}"#);
    let body = URL_SAFE_NO_PAD.encode(payload.as_bytes());
    format!("{header}.{body}.signature")
}
fn mint_user_token(sub: &str, tid: i64) -> String {
    use base64::engine::general_purpose::URL_SAFE_NO_PAD;
    use base64::Engine;
    let header = URL_SAFE_NO_PAD.encode(b"{\"alg\":\"none\",\"typ\":\"JWT\"}");
    let payload = format!(r#"{{"sub":"{sub}","tid":{tid},"roles":["admin"]}}"#);
    let body = URL_SAFE_NO_PAD.encode(payload.as_bytes());
    format!("{header}.{body}.signature")
}

```rust
    /// Publish announcement: split into tx-out IAM fetch + tx-in deliveries + idempotent re-lock.
    /// See doc string in spec §4.3 for full state machine.
    pub async fn publish_announcement(
        &self,
        ann_id: u64,
        iam_client: &IamMemberClient,
        tenant_id: i64,
    ) -> AppResult<Vec<String>> {
        // 1) Open tx 1: lock row, read status, status guard
        let mut tx = self.pool.begin().await?;
        let row: Option<(String, String, i8, i8)> = sqlx::query_as(
            "SELECT title, status, pinned, popover FROM ntf_announcements WHERE id=? FOR UPDATE"
        ).bind(ann_id).fetch_optional(&mut *tx).await?;
        let (title, status, pinned, popover) = match row {
            Some(r) => r,
            None => { tx.commit().await?; return Ok(vec![]); }
        };
        if status == "published" || status == "revoked" {
            tx.commit().await?;
            return Ok(vec![]);
        }
        // release lock before the cross-service HTTP call
        tx.commit().await?;

        // 2) Tx 1 — out: fetch scopes, IAM-fetch role/dept members
        let scopes = self.list_recipient_scopes(ann_id).await?;
        let user_ids: HashSet<String> = if scopes.is_empty() {
            HashSet::new()
        } else {
            iam_client.expand_scopes(&scopes, tenant_id).await?
        };

        // 3) Open tx 2: idempotent re-check + deliveries + status + enqueue
        let mut tx = self.pool.begin().await?;
        let (status_again,): (String,) = sqlx::query_as(
            "SELECT status FROM ntf_announcements WHERE id=? FOR UPDATE"
        ).bind(ann_id).fetch_one(&mut *tx).await?;
        if status_again == "published" || status_again == "revoked" {
            return Ok(vec![]);
        }

        self.insert_deliveries(ann_id, &user_ids).await?;
        // `insert_deliveries` opens its own tx; use the same tx instead:
        // (re-implement below instead)
        for uid in &user_ids {
            sqlx::query(
                "INSERT IGNORE INTO ntf_announcement_deliveries \
                 (announcement_id, user_id, delivered_at) VALUES (?,?,NOW())"
            ).bind(ann_id).bind(uid).execute(&mut *tx).await?;
        }
        sqlx::query("UPDATE ntf_announcements SET status='published' WHERE id=?")
            .bind(ann_id).execute(&mut *tx).await?;
        let mut envelope = Envelope::new(
            "notification-service",
            NotificationAnnouncementPublished {
                announcement_id: ann_id as i64,
                title,
                pinned: pinned != 0,
                popover: popover != 0,
                user_ids: serde_json::json!(user_ids),
            },
        );
        self.outbox_repo.clone()
            .enqueue(&mut tx, &mut envelope).await
            .map_err(|e| AppError::from(anyhow::anyhow!("outbox enqueue: {e}")))?;
        tx.commit().await?;
        Ok(user_ids.iter().cloned().collect())
    }
```

Note: the inline deliveries INSERTs replace the existing `insert_deliveries` call so they share `tx` (call the existing `insert_deliveries` only if it accepts `&mut tx` — currently it doesn't).
