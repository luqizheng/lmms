# Phase 8.3 — 多租户全面贯通 + 跨租户检测 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 收紧 JWT `tid` 缺失为 401、引入 `platform_admin` + `cross_tenant` JWT claim、`TenantScope` 改 enum 编译期保证、`get_claims` 加 tenant 过滤、`scripts/check-tenant-scope.js` CI lint、e2e 跨租户黑名单。

**Architecture:** Gateway 仅收紧 JWT（tid 缺失→401），不解析 body。`TenantScope` 改 enum `{ Single(i64), CrossTenant }`，`and_tenant` 对 `CrossTenant` no-op。`platform_admin` 全局角色 → JWT `ct: true` claim → `Principal.cross_tenant` → `TenantScope::CrossTenant`。`get_claims` 加 `?tenant_id=` query param + SQL 过滤。点查询迁 `QueryBuilder` 以支持 cross_tenant no-op。

**Tech Stack:** Rust + axum + sqlx + utoipa + testcontainers(MySQL) + jwt-ctx::Principal + Node.js lint scripts。

**Spec:** `docs/superpowers/specs/2026-07-04-phase8.3-tenant-hardening-design.md`

```rust
use axum::extract::FromRequestParts;
use axum::http::request::Parts;
use axum::http::StatusCode;
use crate::Principal;

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum TenantScope {
    Single(i64),
    CrossTenant,
}

impl TenantScope {
    pub fn tenant_id(&self) -> Option<i64> {
        match self {
            Self::Single(t) => Some(*t),
            Self::CrossTenant => None,
        }
    }
}

impl<S: Send + Sync> FromRequestParts<S> for TenantScope {
    type Rejection = StatusCode;

    async fn from_request_parts(parts: &mut Parts, state: &S) -> Result<Self, Self::Rejection> {
        let p = Principal::from_request_parts(parts, state).await?;
        Ok(if p.cross_tenant {
            TenantScope::CrossTenant
        } else {
            TenantScope::Single(p.tenant_id)
        })
    }
}
```

```rust
use sqlx::{query_builder::QueryBuilder, Database};
use jwt_ctx::TenantScope;

pub trait WithTenantScope<'a, DB: Database> {
    fn and_tenant(self, scope: &TenantScope) -> Self;
}

impl<'a, DB: Database> WithTenantScope<'a, DB> for QueryBuilder<'a, DB>
where i64: sqlx::Encode<'a, DB> + sqlx::Type<DB>,
{
    fn and_tenant(mut self, scope: &TenantScope) -> Self {
        match scope {
            TenantScope::Single(tid) => {
                self.push(" AND tenant_id = ").push_bind(*tid);
                self
            }
            TenantScope::CrossTenant => self,
        }
    }
}
```

```rust
pub async fn get_claims(&self, user_id: &str, tenant_id: i64) -> Result<UserClaimsResponse, IamError> {
    let user: Option<(String, String, Option<String>, Option<String>, String)> = sqlx::query_as(
        "SELECT id, username, email, phone, nickname FROM iam_users WHERE id = ? AND tenant_id = ? AND deleted_at IS NULL AND status = 'active'"
    )
    .bind(user_id)
    .bind(tenant_id)
    .fetch_optional(&self.state.db)
    .await?;

    let (uid, username, email, phone, nickname) = match user {
        Some(u) => u,
        None => return Err(IamError::UserNotFound),
    };

    let roles: Vec<String> = sqlx::query_scalar(
        "SELECT r.code FROM iam_roles r JOIN iam_user_roles ur ON r.id = ur.role_id JOIN iam_users u ON u.id = ur.user_id WHERE ur.user_id = ? AND u.tenant_id = ? AND r.deleted_at IS NULL"
    )
    .bind(user_id)
    .bind(tenant_id)
    .fetch_all(&self.state.db)
    .await?;

    let permissions: Vec<String> = sqlx::query_scalar(
        "SELECT p.code FROM iam_permissions p JOIN iam_role_permissions rp ON p.id = rp.permission_id JOIN iam_user_roles ur ON rp.role_id = ur.role_id JOIN iam_users u ON u.id = ur.user_id WHERE ur.user_id = ? AND u.tenant_id = ? AND p.deleted_at IS NULL"
    )
    .bind(user_id)
    .bind(tenant_id)
    .fetch_all(&self.state.db)
    .await?;

    let cross_tenant = roles.iter().any(|r| r == "platform_admin");

    Ok(UserClaimsResponse {
        user_id: uid,
        username,
        nickname,
        email,
        phone,
        roles: roles.clone(),
        permissions,
        tenant_id,
        cross_tenant,
    })
}
```

- [ ] **Step 1: 写 check-tenant-scope.js**

Create `scripts/check-tenant-scope.js`:

```javascript
#!/usr/bin/env node
const fs = require('fs');
const path = require('path');
const glob = require('glob');

const RUST_FILES = 'services/*/src/**/*.rs';
const HANDLER_RE = /(?:pub\s+)?async\s+fn\s+(\w+)\s*\(([^)]*)\)/gs;
const HAS_TENANT_SCOPE = /TenantScope/;
const HAS_FILTER = /and_tenant|tenant_id|TenantScope::CrossTenant/;
const EXEMPT = /check-tenant-scope:\s*delegated/;

function extractFunctions(code) {
  const fns = [];
  let m;
  const re = /((?:\/\/.*\n)*)\s*(?:pub\s+)?async\s+fn\s+(\w+)\s*\(/g;
  while ((m = re.exec(code)) !== null) {
    const commentLine = m[1] || '';
    const nameStart = m.index + m[0].length;
    // find matching closing brace
    let depth = 0;
    let i = nameStart;
    // skip to first {
    while (i < code.length && code[i] !== '{') i++;
    const fnStart = i;
    while (i < code.length) {
      if (code[i] === '{') depth++;
      else if (code[i] === '}') { depth--; if (depth === 0) break; }
      i++;
    }
    const body = code.slice(fnStart, i + 1);
    const sig = code.slice(m.index, nameStart);
    const line = code.slice(0, m.index).split('\n').length;
    fns.push({ name: m[2], sig, body, line, comment: commentLine });
  }
  return fns;
}

function checkFile(filePath) {
  const code = fs.readFileSync(filePath, 'utf8');
  const fns = extractFunctions(code);
  const errors = [];
  for (const fn of fns) {
    if (EXEMPT.test(fn.comment)) continue;
    if (HAS_TENANT_SCOPE.test(fn.sig) && !HAS_FILTER.test(fn.body)) {
      errors.push(`${filePath}:${fn.line}: handler "${fn.name}" takes TenantScope but SQL has no tenant_id filter`);
    }
  }
  return errors;
}

function main() {
  const files = glob.sync(RUST_FILES);
  let allErrors = [];
  for (const f of files) {
    allErrors.push(...checkFile(f));
  }
  if (allErrors.length > 0) {
    console.error('check-tenant-scope: FAIL');
    allErrors.forEach(e => console.error('  ' + e));
    process.exit(1);
  }
  console.log('check-tenant-scope: OK');
  process.exit(0);
}

main();
```
