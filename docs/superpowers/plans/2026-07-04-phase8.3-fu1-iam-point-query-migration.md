# Phase 8.3-fu1 — iam-service 点查询 TenantScope 迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate iam-service 的 14 处 point queries + 全部 tenant-scoped 服务方法到 `scope: &TenantScope` + `QueryBuilder`，使 platform_admin 可跨租户访问点查询。

**Architecture:** 服务方法全改 `scope: &TenantScope`（list/点查询/INSERT 统一），handler 增 `TenantScope` extractor（与 `Principal` 共存），新增 `common-db::where_id(id)` helper DRY 点查询样板。SQL 从固定 `WHERE id = ? AND tenant_id = ?` 迁到 `QueryBuilder::new(...).where_id(&id).and_tenant(&scope)`。

**Tech Stack:** Rust + axum + sqlx QueryBuilder + utoipa + testcontainers(MySQL) + jwt-ctx::TenantScope。

**Spec:** `docs/superpowers/specs/2026-07-04-phase8.3-fu1-iam-point-query-migration-design.md`

Modify `libs/common-db/src/scope.rs`：

```rust
use sqlx::{query_builder::QueryBuilder, Database, Encode, Type};

#[cfg(feature = "mysql")]
pub trait WithTenantScope<'a> {
    fn and_tenant(&mut self, scope: &TenantScope) -> &mut Self;
    fn where_id(&mut self, id: impl Encode<'a, sqlx::MySql> + Type<sqlx::MySql> + Send + 'a) -> &mut Self;
}

#[cfg(feature = "mysql")]
impl<'a> WithTenantScope<'a> for QueryBuilder<'a, sqlx::MySql> {
    fn and_tenant(&mut self, scope: &TenantScope) -> &mut Self {
        match scope {
            TenantScope::Single(tid) => {
                self.push(" AND tenant_id = ").push_bind(*tid);
            }
            TenantScope::CrossTenant => {}
        }
        self
    }

    fn where_id(&mut self, id: impl Encode<'a, sqlx::MySql> + Type<sqlx::MySql> + Send + 'a) -> &mut Self {
        self.push(" WHERE id = ").push_bind(id);
        self
    }
}
```

注意：`where_id` 用 `&mut self`（与 `and_tenant` 一致返回 `&mut Self`）而非 `self`。如果调用方需要链式 `QueryBuilder::new(...).where_id(&id).and_tenant(scope).push(...)`，需要 trait 返回 `Self` 而非 `&mut Self`。若编译报链式问题，改为 `self` + 返回 `Self`。
