# Phase 4.4-fu1 `PUT /iam/users/:id/roles` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a new `PUT /iam/users/{user_id}/roles` endpoint in iam-service that fully replaces a user's role set, emits `iam.permission.changed` (reason=`user_roles_changed`), and stamps `perm_epoch` — reusing the Phase 4.4 infrastructure end-to-end.

**Architecture:** New `RoleService::assign_user_roles(user_id, role_ids, actor_id)` runs a single MySQL transaction: `SELECT ... FOR UPDATE` the user row, pre-check role_ids against `iam_roles` (active + not-deleted), read the old set, skip on no-op, otherwise `DELETE + INSERT` via a new shared `set_user_roles_in_tx` helper, then `enqueue_permission_changed` in the same tx. After commit, `stamp_perm_epochs` writes Redis best-effort. Handler in `routes/roles.rs`, DTOs in `dto/role.rs`, no schema migration.

**Tech Stack:** Rust · axum · sqlx (MySQL) · redis (async) · testcontainers · utoipa · thiserror.

## Global Constraints

- All new/moved DB tables and columns keep the `iam_` prefix (already satisfied — no new tables).
- Every permission-changing write MUST enqueue the `iam.permission.changed` outbox event **in the same business transaction** and MUST `stamp_perm_epochs` AFTER commit (best-effort, warn-on-error).
- `contracts-gen --check` and `check-db-naming` must remain clean.
- `perm_epoch` key prefix (`state.redis_prefix`) MUST match gateway `GW_REDIS__PREFIX` — never hardcode.
- The `actor_id` parameter on service signatures is required but stays `None` at handler call sites until Phase 4.4-fu2 lands.
- `PUT /iam/users/{user_id}/roles` behavior: full replace, empty array is valid, invalid role_id → 400, unknown user_id → 404, no-op (dedup-normalized new == old) skips DB writes and event emission.
- Do NOT introduce new permission codes; gateway route-table admin gate is sufficient.
- Every new async DB function using a `Transaction<'_, MySql>` MUST use `&mut *tx` (or `&mut **tx`) style, matching existing code.

```rust
//! Shared helper for writing rows into `iam_user_roles` inside a caller's
//! business transaction. Used by both `UserService::create` (initial role
//! assignment at user creation) and `RoleService::assign_user_roles`
//! (Phase 4.4-fu1 full-replacement endpoint).
//!
//! Empty `role_ids` → no-op. Duplicates in `role_ids` are the caller's
//! responsibility to dedup; a duplicate would violate the `(user_id, role_id)`
//! primary key and abort the transaction.

use sqlx::{MySql, Transaction};

use crate::error::IamError;

pub(crate) async fn set_user_roles_in_tx(
    tx: &mut Transaction<'_, MySql>,
    user_id: &str,
    role_ids: &[String],
) -> Result<(), IamError> {
    for role_id in role_ids {
        sqlx::query(
            "INSERT INTO iam_user_roles (user_id, role_id, created_at) VALUES (?, ?, NOW())",
        )
        .bind(user_id)
        .bind(role_id)
        .execute(&mut **tx)
        .await?;
    }
    Ok(())
}
```

- [ ] **Step 3: Refactor `create_user` to use the helper (keep roles inside the existing tx)**

The current code (`services/iam-service/src/service/user_svc.rs:64-127`) starts a tx for the user INSERT + outbox event, then commits, then runs role INSERTs **outside** the tx. Move the role INSERTs inside the same tx and use the helper.

Read `services/iam-service/src/service/user_svc.rs:44-127` first; the refactor replaces lines ~62-127 with the following ordering:

1. Compute `user_count` **before** starting the tx (line 103-107 stays where it is or moves above the tx, either is fine — do it before `let mut tx = ...`).
2. Compute the final `role_ids: Vec<String>` (including admin-bootstrap append) before starting the tx.
3. Inside the same tx: user INSERT → outbox enqueue → `set_user_roles_in_tx(&mut tx, &user_id, &role_ids)` → commit.
4. After commit, do the `sqlx::query_as` re-select to build `UserResponse` (unchanged).

Concretely, replace lines 62-124 with:

```rust
        // Compute pre-tx state.
        let user_count: (i64,) = sqlx::query_as(
            "SELECT COUNT(*) FROM iam_users WHERE deleted_at IS NULL"
        )
        .fetch_one(&self.state.db)
        .await?;
        let mut role_ids = req.role_ids.clone().unwrap_or_default();
        if user_count.0 == 0 {
            // First user in the system → auto-grant admin. Note: user_count is
            // read before insert, so 0 means "this insert creates user #1".
            let admin_role_id = self.ensure_admin_role().await?;
            role_ids.push(admin_role_id);
        }

        // Insert the user, enqueue the creation event, and write role rows in
        // one transaction (transactional outbox — see libs/digua_common-event +
        // iam_outbox_events).
        let mut tx = self.state.db.begin().await?;
        sqlx::query(
            "INSERT INTO iam_users (id, tenant_id, username, password_hash, salt, nickname, email, phone, avatar, status, email_verified, phone_verified, created_at, updated_at) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, 'active', false, false, NOW(), NOW())"
        )
        .bind(&user_id)
        .bind(1u64)
        .bind(&req.username)
        .bind(&password_hash)
        .bind(&salt)
        .bind(&req.nickname)
        .bind(&req.email)
        .bind(&req.phone)
        .bind(&req.avatar)
        .execute(&mut *tx)
        .await?;

        let mut envelope = Envelope::new(
            "iam-service",
            IamUserCreated {
                user_id: user_id.clone(),
                username: req.username.clone(),
                email: req.email.clone(),
                org_unit_id: None,
            },
        )
        .with_tenant_id(1i64.to_string());
        self.state.outbox_repo.clone()
            .enqueue(&mut tx, &mut envelope)
            .await
            .map_err(|e| IamError::Internal(e.to_string()))?;

        crate::service::user_roles::set_user_roles_in_tx(&mut tx, &user_id, &role_ids).await?;

        tx.commit().await?;

        let user: UserRow = sqlx::query_as(
            "SELECT id, tenant_id, username, email, phone, password_hash, salt, nickname, avatar, status, email_verified, phone_verified, last_login_at, last_login_ip, password_expired_at, created_at, updated_at, deleted_at FROM iam_users WHERE id = ?"
        )
        .bind(&user_id)
        .fetch_one(&self.state.db)
        .await?;
```

**Important**: the original `user_count.0 == 1` check compares against the value **after** insert (see the original code path — it reads count after commit). The refactor moves the read **before** insert, so the condition changes to `== 0`. This preserves the "the very first user in the system gets admin" semantic. // ---- outbox helpers ----

```rust
async fn outbox_count(state: &AppState) -> i64 {
    let (n,): (i64,) = sqlx::query_as(
        "SELECT COUNT(*) FROM iam_outbox_events WHERE event_type = 'iam.permission.changed'",
    ).fetch_one(&state.db).await.unwrap();
    n
}

async fn single_outbox_reason_and_users(state: &AppState) -> (String, BTreeSet<String>) {
    assert_eq!(outbox_count(state).await, 1, "expected exactly one iam.permission.changed row");
    let (reason, users_json): (String, String) = sqlx::query_as(
        "SELECT CAST(JSON_UNQUOTE(JSON_EXTRACT(envelope_json, '$.payload.reason')) AS CHAR), \
                CAST(JSON_EXTRACT(envelope_json, '$.payload.user_ids') AS CHAR) \
         FROM iam_outbox_events WHERE event_type = 'iam.permission.changed'",
    ).fetch_one(&state.db).await.unwrap();
    let users: Vec<String> = serde_json::from_str(&users_json).unwrap();
    (reason, users.into_iter().collect())
}

async fn user_roles(state: &AppState, user_id: &str) -> BTreeSet<String> {
    let rows: Vec<(String,)> = sqlx::query_as(
        "SELECT role_id FROM iam_user_roles WHERE user_id = ?"
    ).bind(user_id).fetch_all(&state.db).await.unwrap();
    rows.into_iter().map(|(r,)| r).collect()
}

async fn assert_epoch_fresh(ctx: &mut Ctx, uid: &str, before: i64) {
    let epoch = get_perm_epoch(&mut ctx.redis, PREFIX, uid).await.unwrap()
        .unwrap_or_else(|| panic!("perm_epoch missing for {uid}"));
    let after = chrono::Utc::now().timestamp();
    assert!(epoch >= before && epoch <= after, "epoch {epoch} for {uid} not in [{before}, {after}]");
    let key = perm_epoch_key(PREFIX, uid);
    let ttl: i64 = redis::cmd("TTL").arg(&key).query_async(&mut ctx.redis).await.unwrap();
    assert!(ttl > 0, "expected TTL > 0 for {key}, got {ttl}");
}

async fn assert_no_epoch(ctx: &mut Ctx, uid: &str) {
    let epoch = get_perm_epoch(&mut ctx.redis, PREFIX, uid).await.unwrap();
    assert_eq!(epoch, None, "expected no perm_epoch for {uid}");
}

fn set_of(items: &[&str]) -> BTreeSet<String> {
    items.iter().map(|s| s.to_string()).collect()
}

#[tokio::test]
async fn assign_user_roles_replaces_and_emits_event() {
    let mut ctx = setup().await;
    seed_user(&ctx.state, "u1").await;
    seed_role(&ctx.state, "r1").await;
    seed_role(&ctx.state, "r2").await;

    let before = chrono::Utc::now().timestamp();
    let ret = RoleService::new(ctx.state.clone())
        .assign_user_roles("u1", vec!["r1".into(), "r2".into()], None)
        .await
        .unwrap();

    assert_eq!(user_roles(&ctx.state, "u1").await, set_of(&["r1", "r2"]));

    let (reason, users) = single_outbox_reason_and_users(&ctx.state).await;
    assert_eq!(reason, "user_roles_changed");
    assert_eq!(users, set_of(&["u1"]));
    assert_epoch_fresh(&mut ctx, "u1", before).await;
}
```

```rust
    /// Full-replace a user's role set. Empty `role_ids` is legal (clears).
    /// Duplicate ids in `role_ids` are deduped. Returns the resulting canonical
    /// role_ids (sorted). No-op (new == old after dedup) → returns Ok without
    /// touching the DB, enqueuing an event, or stamping perm_epoch.
    ///
    /// Errors:
    /// - `IamError::UserNotFound` — user_id absent or soft-deleted
    /// - `IamError::InvalidRoleIds(v)` — v lists role_ids not found as active
    pub async fn assign_user_roles(
        &self,
        user_id: &str,
        role_ids: Vec<String>,
        actor_id: Option<&str>,
    ) -> Result<Vec<String>, IamError> {
        let mut tx = self.state.db.begin().await?;

        // 1) user existence + row lock
        let exists: Option<(String,)> = sqlx::query_as(
            "SELECT id FROM iam_users WHERE id = ? AND deleted_at IS NULL FOR UPDATE",
        )
        .bind(user_id)
        .fetch_optional(&mut *tx)
        .await?;
        if exists.is_none() {
            return Err(IamError::UserNotFound);
        }

        // 2) dedup + pre-check role_ids (active + not soft-deleted)
        let dedup: Vec<String> = {
            let s: BTreeSet<String> = role_ids.into_iter().collect();
            s.into_iter().collect()
        };
        if !dedup.is_empty() {
            let placeholders = std::iter::repeat("?").take(dedup.len()).collect::<Vec<_>>().join(",");
            let sql = format!(
                "SELECT id FROM iam_roles WHERE id IN ({}) AND status='active' AND deleted_at IS NULL",
                placeholders
            );
            let mut q = sqlx::query_as::<_, (String,)>(&sql);
            for id in &dedup {
                q = q.bind(id);
            }
            let found: Vec<(String,)> = q.fetch_all(&mut *tx).await?;
            let found_set: HashSet<&str> = found.iter().map(|(s,)| s.as_str()).collect();
            let invalid: Vec<String> = dedup
                .iter()
                .filter(|id| !found_set.contains(id.as_str()))
                .cloned()
                .collect();
            if !invalid.is_empty() {
                return Err(IamError::InvalidRoleIds(invalid));
            }
        }

        // 3) read old set → diff-skip
        let old: Vec<(String,)> = sqlx::query_as(
            "SELECT role_id FROM iam_user_roles WHERE user_id = ?",
        )
        .bind(user_id)
        .fetch_all(&mut *tx)
        .await?;
        let old_set: BTreeSet<String> = old.into_iter().map(|(r,)| r).collect();
        let new_set: BTreeSet<String> = dedup.iter().cloned().collect();
        if old_set == new_set {
            tx.commit().await?;
            return Ok(new_set.into_iter().collect());
        }

        // 4) full replace
        sqlx::query("DELETE FROM iam_user_roles WHERE user_id = ?")
            .bind(user_id)
            .execute(&mut *tx)
            .await?;
        crate::service::user_roles::set_user_roles_in_tx(&mut tx, user_id, &dedup).await?;

        // 5) same-tx outbox event
        crate::service::perm_change::enqueue_permission_changed(
            &mut tx,
            self.state.outbox_repo.as_ref(),
            &[user_id.to_string()],
            "user_roles_changed",
            actor_id,
        )
        .await?;

        tx.commit().await?;

        // 6) post-commit best-effort Redis stamp
        crate::service::perm_change::stamp_perm_epochs(&self.state, &[user_id.to_string()]).await;

        Ok(new_set.into_iter().collect())
    }
```

**Verification hints for the implementer:**
- `enqueue_permission_changed`'s first parameter is `&mut Transaction<'_, MySql>` (see `services/iam-service/src/service/perm_change.rs:21-44`); pass `&mut tx` directly, not `&mut *tx`.
- `self.state.outbox_repo` type is `Arc<MySqlOutboxRepo>`; `.as_ref()` produces `&MySqlOutboxRepo`, which matches the `repo: &MySqlOutboxRepo` parameter.
- `stamp_perm_epochs(&self.state, &[...])` — returns `()`, does its own warn-logging, never Err.
