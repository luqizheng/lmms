## 1. 1.5 定位与边界

### 1.1 命名

- **版本号**：v1.5.0（继 v1.0.0 之后下一主发布的次版本）
- **阶段名**：1.5 阶段 / 8 月发布周期（口语化）
- **覆盖时间窗**：2026-08-19 → 2026-09-15（4 周）
- **目标发布物**：
  1. `release/dist-template` v1.5.0 离线分发包（基于 v1.0.0 增量）
  2. 一份 8 月 Retrospective（关闭 8 月发布周期）
  3. 一份 1.6 阶段提案（开 1.6 周期）

### 1.2 1.5 要解决的 4 类问题

| 问题类别 | 描述 | 对应交付 |
|---|---|---|
| A. 8 月提案未动项 | 8 月提案 P2 warning / P4 弹性 / 模板补段未启动 | P2 + P4 闭环 + 模板升级 |

| C. 文档与现实漂移 | ADR 矩阵已扩展到 004 / 007，但 `docs/superpowers/retros/` 缺 8 月 | retro 闭合 |

| 放弃项 | 理由 |

### 4.2 互斥与依赖

- **W2 warning 清偿** 必须在 W3 OTel 扩展**之前**完成：补 summary 时会改 service 路由 annotation，OTel env 注入会改 compose，如果乱序会触发 OpenAPI drift + compose 漂移。
- **W1 模板升级** 必须在 W2 模板迁移**之前**完成：模板先行 → 旧 spec 迁移才有目标。
- **W4 1.5 retro** 必须先有 W1-W3 的实际证据：retro 反映实际进展。
- **W4 v1.5.0 打包** 必须在 W3 OTel 完工 + W2 警告清零 + W1 retro 完工后：否则离线包内含未关债项。

### 4.3 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| W2 warning 清偿子 agent 失败 / 引入新 drift | 中 | 高 | 限定子 agent 改 `summary` 字段 + 禁止改 route handler；写入 1 task = 1 service 边界 |

| ResilientClient 接入破坏既有 5B-fu6 测试 | 中 | 高 | 先在 1 个 service 试点，验证后扩面 |

| 8 月 retro 漏项（如忘归档 8 月 17 日 spec） | 中 | 低 | 写 retro 时用 `git log --since='2026-07-23' --until='2026-08-19'` 拉全 commit |
