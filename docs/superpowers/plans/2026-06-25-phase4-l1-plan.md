# Phase 4 L1 Production Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 8 个服务的 health 分级 + 优雅停机、CVE 闸门、5 个 SLO + alertmanager 链路、跨服务 trace 自动断言全部上线，并以 `pnpm run check:readiness` 一条命令收口。

**Architecture:** 4 个独立子系统并行推进：(1) 新 `libs/common-health` crate + 8 个 main.rs 切到 `with_graceful_shutdown`；(2) CI 加 `cargo audit` + `trivy image` + ignore expiry 守护；(3) `infrastructure/config/prometheus/alerts.yml` + `alertmanager.yml` + 新建 `services/mock-webhook/`；(4) 4 个 service 开 `common-telemetry` 的 `otlp` feature + `x-trace-id` 响应头 + e2e Jaeger query 断言。

**Tech Stack:** Rust 1.96 + axum 0.8 + sqlx + prometheus 0.13 / Node 20 / cargo-audit + Trivy / Prometheus 2.x + Alertmanager 0.27 / Playwright + OTel 0.17 + Jaeger 1.x。

## Global Constraints

- 不改对外 HTTP 契约；新端点只在 `/health/live` `/health/ready` 路径下，`/health` 保留为兼容路径返回 `200 "OK"`。
- 4 个子系统互不依赖，可任意顺序合入 main；本计划按 Task 1→10 串行写出，Task 4+5、6+7、8+9 三组内部可并行 subagent。
- 所有 Rust 改动通过 `node scripts/run-tests-docker.js <crate>` 在 Docker 中跑 `cargo test`，不在宿主机直接 `cargo build`（已知 WSL/macOS linker 坑，见 `docs-site/ai-context.md` § 7 #2）。
- 网络访问 GitHub 必须走 `gh-proxy.org`；扫描器镜像走内网 `zhcoder-docker-registry.com:8000`；rust 镜像用 `zhcoder-docker-registry.com:8000/official/rust:1.96-slim`。
- 严格度：CVE high/critical 阻断；low/medium 警告。ignore 条目必须三段注释：`# reason:` `# expires: YYYY-MM-DD` `# owner:`。
- mock-webhook 是 dev/CI 工具，**不打生产镜像**；在 `services/mock-webhook/AGENTS.md` 的 `## 豁免` 段声明 `/metrics`、`migrations/ 目录`、`Swagger 配置`、`优雅停机` 四项豁免。

- 每个 Rust crate 改动后跑 `node scripts/run-tests-docker.js <crate>`，全 PASS 才 commit。

```rust
//! Health probes (live + ready) and graceful-shutdown shared state.

use axum::{
    extract::State,
    http::StatusCode,
    response::IntoResponse,
    routing::get,
    Json, Router,
};
use once_cell::sync::Lazy;
use prometheus::{register_int_gauge_vec, IntGauge, IntGaugeVec};
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;
use std::time::Duration;

static SERVICE_READY: Lazy<IntGaugeVec> = Lazy::new(|| {
    register_int_gauge_vec!(
        "service_ready",
        "1 when /health/ready returns 200; 0 otherwise",
        &["service"]
    ).expect("service_ready gauge registration")
});

#[derive(Clone)]
pub struct HealthState {
    service_name: &'static str,
    db: Option<sqlx::AnyPool>,
    redis: Option<redis::aio::ConnectionManager>,
    consul_addr: Option<String>,
    shutting_down: Arc<AtomicBool>,
    ready_gauge: IntGauge,
}

impl HealthState {
    pub fn new(service_name: &'static str) -> Self {
        let ready_gauge = SERVICE_READY.with_label_values(&[service_name]);
        ready_gauge.set(0);
        Self {
            service_name,
            db: None,
            redis: None,
            consul_addr: None,
            shutting_down: Arc::new(AtomicBool::new(false)),
            ready_gauge,
        }
    }
    pub fn with_db(mut self, pool: sqlx::AnyPool) -> Self { self.db = Some(pool); self }
    pub fn with_mysql(mut self, pool: sqlx::MySqlPool) -> Self {
        self.db = Some(sqlx::AnyPool::from(pool));
        self
    }
    pub fn with_sqlite(mut self, pool: sqlx::SqlitePool) -> Self {
        self.db = Some(sqlx::AnyPool::from(pool));
        self
    }
    pub fn with_redis(mut self, conn: redis::aio::ConnectionManager) -> Self {
        self.redis = Some(conn); self
    }
    pub fn with_consul(mut self, addr: impl Into<String>) -> Self {
        self.consul_addr = Some(addr.into()); self
    }
    pub fn mark_shutting_down(&self) {
        self.shutting_down.store(true, Ordering::SeqCst);
        self.ready_gauge.set(0);
        tracing::info!(service = self.service_name, "marked NOT ready (shutting down)");
    }
    pub fn is_shutting_down(&self) -> bool {
        self.shutting_down.load(Ordering::SeqCst)
    }
    fn mark_ready(&self) { self.ready_gauge.set(1); }
}

pub fn health_routes(state: HealthState) -> Router {
    Router::new()
        .route("/health", get(legacy))
        .route("/health/live", get(live))
        .route("/health/ready", get(ready))
        .with_state(state)
}

async fn legacy() -> &'static str { "OK" }
async fn live() -> &'static str { "OK" }

async fn ready(State(s): State<HealthState>) -> impl IntoResponse {
    if s.is_shutting_down() {
        s.ready_gauge.set(0);
        return (StatusCode::SERVICE_UNAVAILABLE,
            Json(serde_json::json!({"status": "shutting_down"})));
    }
    let mut report = serde_json::Map::new();
    let mut ok = true;

    if let Some(pool) = &s.db {
        match tokio::time::timeout(Duration::from_secs(1),
            sqlx::query("SELECT 1").execute(pool)).await {
            Ok(Ok(_)) => { report.insert("db".into(), "ok".into()); }
            _ => { report.insert("db".into(), "fail".into()); ok = false; }
        }
    }

    if let Some(conn) = &s.redis {
        let mut conn = conn.clone();
        match tokio::time::timeout(Duration::from_millis(500),
            redis::cmd("PING").query_async::<_, String>(&mut conn)).await {
            Ok(Ok(_)) => { report.insert("redis".into(), "ok".into()); }
            _ => { report.insert("redis".into(), "fail".into()); ok = false; }
        }
    }

    if let Some(addr) = &s.consul_addr {
        let host_port = addr.trim_start_matches("http://").trim_start_matches("https://");
        let host_port = host_port.split('/').next().unwrap_or(host_port);
        match tokio::time::timeout(Duration::from_millis(200),
            tokio::net::TcpStream::connect(host_port)).await {
            Ok(Ok(_)) => { report.insert("consul".into(), "ok".into()); }
            _ => { report.insert("consul".into(), "fail".into()); ok = false; }
        }
    }

    if ok {
        s.mark_ready();
        (StatusCode::OK, Json(serde_json::Value::Object(report)))
    } else {
        s.ready_gauge.set(0);
        (StatusCode::SERVICE_UNAVAILABLE, Json(serde_json::Value::Object(report)))
    }
}

/// SIGTERM/SIGINT 来时：mark shutting_down → drain → 返回
pub async fn shutdown_signal(state: HealthState) {
    let sigterm = async {
        #[cfg(unix)]
        {
            use tokio::signal::unix::{signal, SignalKind};
            if let Ok(mut s) = signal(SignalKind::terminate()) { s.recv().await; }
            else { std::future::pending::<()>().await; }
        }
        #[cfg(not(unix))]
        { std::future::pending::<()>().await; }
    };
    let sigint = tokio::signal::ctrl_c();
    tokio::select! {
        _ = sigterm => tracing::info!("SIGTERM received"),
        _ = sigint => tracing::info!("SIGINT received"),
    }
    state.mark_shutting_down();
    let drain_secs: u64 = std::env::var("SHUTDOWN_DRAIN_SECS").ok()
        .and_then(|v| v.parse().ok()).unwrap_or(5);
    tracing::info!(secs = drain_secs, "draining before close");
    tokio::time::sleep(Duration::from_secs(drain_secs)).await;
}
```

```javascript
#!/usr/bin/env node
/**
 * CVE 闸门本地等价：cargo audit + 可选 trivy image
 * 严格度：HIGH/CRITICAL exit 1；LOW/MEDIUM 报告但 exit 0。
 * 缺工具：本地 warn skip；CI 强制 exit 1（通过 CI=true 检测）。
 */
const { spawnSync } = require('node:child_process');
const fs = require('node:fs');
const path = require('node:path');

const IS_CI = process.env.CI === 'true' || process.env.GITLAB_CI === 'true';

function which(cmd) {
  const r = spawnSync('which', [cmd], { encoding: 'utf-8' });
  return r.status === 0 ? r.stdout.trim() : null;
}

function runCargoAudit() {
  console.log('\n=== cargo audit ===');
  if (!which('cargo-audit') && !which('cargo')) {
    const msg = 'cargo-audit/cargo not installed';
    if (IS_CI) { console.error(`❌ ${msg}`); return 1; }
    console.warn(`⚠️  ${msg} (skipped in local mode)`);
    return 0;
  }
  const r = spawnSync('cargo', ['audit', '--color', 'never', '--json'], { encoding: 'utf-8' });
  let parsed;
  try { parsed = JSON.parse(r.stdout || '{}'); }
  catch (e) {
    console.error('failed to parse cargo audit json output');
    console.error(r.stdout);
    return 1;
  }
  const vulns = parsed?.vulnerabilities?.list ?? [];
  let critical = 0, high = 0, other = 0;
  for (const v of vulns) {
    const sev = (v?.advisory?.severity ?? 'unknown').toLowerCase();
    if (sev === 'critical') critical++;
    else if (sev === 'high') high++;
    else other++;
    console.log(`  ${sev.toUpperCase().padEnd(8)} ${v?.advisory?.id} ${v?.advisory?.title}`);
  }
  console.log(`\n  critical=${critical} high=${high} other=${other}`);
  if (critical + high > 0) {
    console.error('❌ cargo audit: high/critical present');
    return 1;
  }
  console.log('✅ cargo audit clean (or only low/medium)');
  return 0;
}

function runTrivy(image) {
  if (!which('trivy')) {
    const msg = `trivy not installed; skip ${image}`;
    if (IS_CI) { console.error(`❌ ${msg}`); return 1; }
    console.warn(`⚠️  ${msg}`);
    return 0;
  }
  console.log(`\n=== trivy ${image} ===`);
  const ignoreFile = path.join(__dirname, '..', '.trivyignore');
  const args = ['image', '--severity', 'HIGH,CRITICAL', '--exit-code', '1', '--no-progress'];
  if (fs.existsSync(ignoreFile)) args.push('--ignorefile', ignoreFile);
  args.push(image);
  const r = spawnSync('trivy', args, { stdio: 'inherit' });
  return r.status ?? 0;
}

function main() {
  const targets = (process.env.TRIVY_TARGETS || '').split(',').filter(Boolean);
  let code = 0;
  code |= runCargoAudit();
  for (const img of targets) code |= runTrivy(img);
  if (code === 0) console.log('\n✅ CVE 闸门全绿');
  else console.error('\n❌ CVE 闸门未通过');
  process.exit(code);
}
main();
```

```javascript
#!/usr/bin/env node
/**
 * 扫描 .cargo/audit.toml 与 .trivyignore，检查每条 ignore 的 # expires: YYYY-MM-DD
 * - 过期 → exit 1
 * - 14 天内过期 → warn but exit 0
 */
const fs = require('node:fs');
const path = require('node:path');

const FILES = [
  path.join(__dirname, '..', '.cargo', 'audit.toml'),
  path.join(__dirname, '..', '.trivyignore'),
];
const EXPIRY_RE = /#\s*expires:\s*(\d{4}-\d{2}-\d{2})/i;
const REASON_RE = /#\s*reason:/i;
const OWNER_RE = /#\s*owner:/i;

function checkFile(file) {
  if (!fs.existsSync(file)) { console.log(`(skip: ${file} missing)`); return { errors: 0, warnings: 0 }; }
  const content = fs.readFileSync(file, 'utf-8');
  const lines = content.split('\n');
  const blocks = [];
  let curr = [];
  for (const line of lines) {
    if (line.trim() === '') {
      if (curr.length) blocks.push(curr.join('\n'));
      curr = [];
    } else curr.push(line);
  }
  if (curr.length) blocks.push(curr.join('\n'));

  let errors = 0, warnings = 0;
  const today = new Date();
  const in14 = new Date(today.getTime() + 14 * 86400 * 1000);

  for (const blk of blocks) {
    if (!EXPIRY_RE.test(blk)) continue;
    const expDate = new Date(blk.match(EXPIRY_RE)[1]);
    if (!REASON_RE.test(blk) || !OWNER_RE.test(blk)) {
      console.error(`❌ ${file}: ignore 条目缺 # reason / # owner\n${blk}\n`);
      errors++;
      continue;
    }
    if (expDate < today) {
      console.error(`❌ ${file}: ignore 已于 ${expDate.toISOString().slice(0,10)} 过期\n${blk}\n`);
      errors++;
    } else if (expDate < in14) {
      console.warn(`⚠️  ${file}: ignore 将于 ${expDate.toISOString().slice(0,10)} 过期 (<14d)\n${blk}\n`);
      warnings++;
    }
  }
  return { errors, warnings };
}

let totalErrors = 0, totalWarnings = 0;
for (const f of FILES) {
  const r = checkFile(f);
  totalErrors += r.errors;
  totalWarnings += r.warnings;
}
if (totalErrors > 0) {
  console.error(`\n❌ CVE ignore expiry check 未通过 (errors=${totalErrors} warnings=${totalWarnings})`);
  process.exit(1);
}
console.log(`\n✅ CVE ignore expiry OK (warnings=${totalWarnings})`);
```

```rust
use axum::{extract::State, http::StatusCode, response::IntoResponse,
           routing::{get, post}, Json, Router};
use parking_lot::Mutex;
use std::collections::VecDeque;
use std::sync::Arc;

const CAP: usize = 100;

#[derive(Clone, Default)]
pub struct WebhookStore {
    inner: Arc<Mutex<VecDeque<serde_json::Value>>>,
}

impl WebhookStore {
    pub fn push(&self, v: serde_json::Value) {
        let mut g = self.inner.lock();
        g.push_back(v);
        while g.len() > CAP { g.pop_front(); }
    }
    pub fn all(&self) -> Vec<serde_json::Value> {
        self.inner.lock().iter().cloned().collect()
    }
    pub fn clear(&self) { self.inner.lock().clear(); }
}

pub fn router() -> Router {
    let store = WebhookStore::default();
    Router::new()
        .route("/webhook", post(receive))
        .route("/webhook/received", get(list).delete(clear))
        .route("/health", get(|| async { "OK" }))
        .route("/health/live", get(|| async { "OK" }))
        .route("/health/ready", get(|| async { "OK" }))
        .with_state(store)
}

async fn receive(State(s): State<WebhookStore>, Json(v): Json<serde_json::Value>) -> impl IntoResponse {
    tracing::info!("webhook received: {}", serde_json::to_string(&v).unwrap_or_default());
    s.push(v);
    StatusCode::OK
}
async fn list(State(s): State<WebhookStore>) -> Json<Vec<serde_json::Value>> {
    Json(s.all())
}
async fn clear(State(s): State<WebhookStore>) -> StatusCode {
    s.clear(); StatusCode::OK
}
```

```rust
/// axum middleware: 把当前 tracing span 的 trace_id 写入 `x-trace-id` 响应头。
/// 不依赖 otlp feature；OTel 未启用时返回 32 个 0。
pub async fn trace_id_response_header(
    req: axum::http::Request<axum::body::Body>,
    next: axum::middleware::Next,
) -> axum::response::Response {
    let mut res = next.run(req).await;
    let trace_id = current_trace_id();
    if let Ok(v) = axum::http::HeaderValue::from_str(&trace_id) {
        res.headers_mut().insert("x-trace-id", v);
    }
    res
}

#[cfg(feature = "otlp")]
fn current_trace_id() -> String {
    use opentelemetry::trace::TraceContextExt;
    use tracing_opentelemetry::OpenTelemetrySpanExt;
    let span = tracing::Span::current();
    let ctx = span.context();
    ctx.span().span_context().trace_id().to_string()
}

#[cfg(not(feature = "otlp"))]
fn current_trace_id() -> String {
    "0".repeat(32)
}
```

```ts
import { test, expect } from '@playwright/test'

const gw = process.env.E2E_BASE_URL || 'http://localhost:3000'
const jaegerQuery = process.env.JAEGER_QUERY_URL || 'http://localhost:16686'

async function pollJaeger(traceId: string, expectServices: string[], timeoutMs: number) {
  const deadline = Date.now() + timeoutMs
  let lastReason = 'no attempt'
  while (Date.now() < deadline) {
    try {
      const r = await fetch(`${jaegerQuery}/api/traces/${traceId}`)
      if (r.status === 200) {
        const j: any = await r.json()
        const spans = j?.data?.[0]?.spans ?? []
        const services = new Set<string>(
          spans.map((s: any) => s.process?.serviceName).filter(Boolean)
        )
        const missing = expectServices.filter(s => !services.has(s))
        if (missing.length === 0) return { ok: true, services: [...services] }
        lastReason = `missing=${missing.join(',')} have=${[...services].join(',')}`
      } else {
        lastReason = `jaeger ${r.status}`
      }
    } catch (e: any) {
      lastReason = `fetch error ${e?.message ?? e}`
    }
    await new Promise(r => setTimeout(r, 1000))
  }
  return { ok: false, reason: lastReason }
}

test.describe('cross-service trace propagation', () => {
  test('gateway → iam trace appears in jaeger', async () => {
    test.setTimeout(120_000)

    // 通过 gateway 调一个会跨多个 service 的 endpoint。
    const res = await fetch(`${gw}/api/v1/iam/auth/login`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ username: 'admin', password: 'admin' }),
    })
    // 不 assert status：401/200 都可以，只需要 trace 走完。
    const traceId = res.headers.get('x-trace-id')
    expect(traceId).toMatch(/^[0-9a-f]{32}$/)
    expect(traceId).not.toBe('0'.repeat(32))

    const out = await pollJaeger(traceId!, ['api-gateway', 'iam-service'], 60_000)
    expect(out.ok, `jaeger trace check: ${(out as any).reason}`).toBe(true)
  })

  test('audit log path trace propagation (optional)', async () => {
    test.setTimeout(120_000)
    const res = await fetch(`${gw}/api/v1/iam/auth/login`, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify({ username: 'admin', password: 'admin' }),
    })
    const traceId = res.headers.get('x-trace-id')
    test.skip(!traceId || traceId === '0'.repeat(32), 'no trace id; OTel may be disabled')

    // audit log 通常异步入库，给 jaeger 多 30s 收集
    const out = await pollJaeger(traceId!, ['api-gateway', 'iam-service'], 90_000)
    expect(out.ok).toBe(true)
    // audit-service span 可选：audit 写库是 async tokio::spawn，可能未在同 trace；
    // 不强 assert，保留为下一阶段 (L2) 加强。
  })
```

```markdown
## 上下文

12 周 roadmap 完成后，系统在 dev 环境闭环但没人敢上 staging：缺优雅停机、readiness 分级、CVE 闸门、SLO 定义、跨服务 trace 自动断言。

## 决议

### 1. 必需组件升级到 10 项（含 health 双探针 + 优雅停机）

ADR-002 的 8 项扩为 10 项：
- 新加：`/health/ready` 端点（含 DB ping + Redis ping 并发检查）
- 新加：优雅停机（`with_graceful_shutdown` + `common-health::shutdown_signal`）
- 修改：`/health 端点` 接受 `/health` 或 `/health/live` 任一存在（向后兼容）

### 2. CVE 严格度

- HIGH + CRITICAL → CI 阻断 merge/deploy
- LOW + MEDIUM → 报告但 exit 0
- 例外通过 `.cargo/audit.toml` / `.trivyignore` 显式声明，每条带 `# reason / # expires / # owner`

### 3. 5 个 SLO

详见 `docs/slo.md`：gateway-5xx-rate / token-issue-p99 / iam-login-p99 / readiness-fail / e2e-smoke-cron

### 4. 告警链路

Prometheus alerts.yml → alertmanager.yml → mock-webhook (dev/CI) 或 企微/钉钉 (生产，仅改 webhook url)

### 5. 跨服务 trace 验证

OTel collector + Jaeger query API + e2e trace.spec.ts 断言 ≥2 个 service span

### 6. CI 闸门

test 阶段新增：`cargo_audit` / `cve_expiry_check` / `e2e_trace`
build 阶段新增：`trivy_scan`（parallel matrix）

本地等价：`pnpm run check:readiness`（不含 docker e2e；e2e 独立通过 CI 跑）

## 后果

- 新服务必须满足 10 项基线（mock-webhook 是 dev/CI 工具，4 项豁免）
- 滚动发布：SIGTERM 后 readiness 立即切 false，drain 5s 后 deregister consul，无 5xx
- CVE 出现时必须显式 ignore 或修，过期 ignore 14 天内 warn / 过期阻断
- 5 SLO 任一红 → alertmanager 推 mock-webhook / 企微，值班人有明确响应路径
- 跨服务 trace 自动验证：每次 e2e 跑保证 OTel 链路活着
```
