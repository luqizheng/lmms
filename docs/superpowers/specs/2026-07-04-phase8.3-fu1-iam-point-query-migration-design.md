## 1. 背景与问题

Phase 8.3 完成后，list 查询已支持 `TenantScope::CrossTenant`（platform_admin 跨租户可见），但 point queries（get/update/delete by id）仍用固定 SQL + `.bind(tid)` 模式：

```rust
// 当前模式（8.3 前实现，8.3 未动）
sqlx::query("SELECT ... FROM iam_users WHERE id = ? AND tenant_id = ?")
    .bind(id)
    .bind(tid)  // 来自 principal.tenant_id
    .fetch_optional(...)
```

后果：platform_admin 调 `GET /iam/users/{其他租户 id}` → handler 传 `principal.tenant_id=1`（default 租户） → SQL `WHERE id = X AND tenant_id = 1` → 返回 0 行（永远 404，即使 record 存在）。

跨租户 list 已 work，但跨租户 point query 失效 — 架构未闭环。

---

## 2. 目标 / 非目标

### 目标

1. **iam-service 所有 tenant-scoped 资源点查询支持 `CrossTenant`**：platform_admin 可通过 id 访问任意租户记录（用于 support/debugging）
2. **服务方法签名统一**：所有 tenant-scoped 方法从 `tenant_id: i64` 改为 `scope: &TenantScope`（list、点查询、INSERT 全改）
3. **handler 签名调整**：取 `TenantScope` extractor（与 `Principal` 共存当需要其他字段）
4. **`common-db` 新增 `where_id` helper**：DRY 点查询样板

### 非目标

- ntf/cfg/file 点查询 → 8.3-fu2
- INSERT tenant_id 取值优化（保持 `unwrap_or(1)` 兜底）
- actor_id / audit trail 改造（不在本任务）

## 3. 设计

### 3.1 架构总览

```
┌─ handlers (org_units.rs / roles.rs / users.rs) ─┐
│ 旧: Principal { tenant_id, .. }: Principal       │
│ 新: Principal { user_id, .. }: Principal,        │
│     TenantScope(scope): TenantScope              │
│     ↓ 或仅 TenantScope (不需要 Principal 字段)    │
└─────────────────────────────────────────────────┘
          │ service.method(..., &scope, ...)
          ▼
┌─ services (org_svc / role_svc / user_svc) ─────┐
│ 旧: fn get(&self, id: &str, tenant_id: i64)     │
│ 新: fn get(&self, id: &str, scope: &TenantScope)│
│   内部: QueryBuilder + and_tenant(scope)         │
└─────────────────────────────────────────────────┘
          │
          ▼ CrossTenant → and_tenant no-op
   platform_admin 可跨租户访问
```

### 3.2 Handler 签名变化

**只取 tenant 的 handler**（当前 `Principal { tenant_id, .. }`）：
```rust
// 旧
async fn get_user(
    State(state): State<AppState>,
    Principal { tenant_id, .. }: Principal,
    Path(id): Path<String>,
) -> ...

// 新
async fn get_user(
    State(state): State<AppState>,
    scope: TenantScope,
    Path(id): Path<String>,
) -> ...
```

**需要 Principal 字段的 handler**（如 `assign_users` 要 `user_id` 做 actor_id、`delete role` 要 `actor_id`）：
```rust
// 旧
async fn delete_role(
    State(state): State<AppState>,
    Principal { user_id, tenant_id, .. }: Principal,
    Path(id): Path<String>,
) -> ...

// 新
async fn delete_role(
    State(state): State<AppState>,
    Principal { user_id, .. }: Principal,
    scope: TenantScope,
    Path(id): Path<String>,
) -> ...
```

### 3.3 Service 方法签名

所有 `tenant_id: i64` → `scope: &TenantScope`：

```rust
// 点查询（get）
pub async fn get(&self, id: &str, scope: &TenantScope) -> Result<X, IamError> {
    QueryBuilder::new("SELECT ... FROM foo")
        .where_id(id)
        .and_tenant(scope)
        .push(" AND deleted_at IS NULL")
        .build_query_as::<X>()
        .fetch_optional(&self.state.db).await?
}

// 列表查询（8.3 已迁，此处统一签名）
pub async fn list(&self, query: X, scope: &TenantScope) -> Result<X, IamError> {
    let mut qb = QueryBuilder::new("SELECT ... FROM foo WHERE deleted_at IS NULL");
    qb.and_tenant(scope);
    qb.push(" ORDER BY ...");
    qb.build_query_as::<X>().fetch_all(&self.state.db).await?
}

// INSERT
pub async fn create(&self, req: CreateReq, scope: &TenantScope) -> Result<X, IamError> {
    let tenant_id = scope.tenant_id().unwrap_or(1);
    sqlx::query("INSERT INTO foo (... tenant_id) VALUES (...)")
        .bind(tenant_id)
        .execute(&self.state.db).await?;
}

// UPDATE/DELETE 点查询
pub async fn update(&self, id: &str, req: UpdateReq, scope: &TenantScope) -> Result<X, IamError> {
    let mut qb = QueryBuilder::new("UPDATE foo SET ... = ");
    qb.push_bind(req.field);
    qb.push(" WHERE id = ");
    qb.push_bind(id);
    qb.and_tenant(scope);
    qb.push(" AND deleted_at IS NULL");
    qb.build().execute(&self.state.db).await?;
}
```

### 3.4 共享 helper（DRY）

为减少重复 `QueryBuilder::new + push_bind(id) + and_tenant` 样板，新增 helper：

```rust
// libs/common-db/src/scope.rs
pub trait WithTenantScope<'a, DB: Database> {
    fn where_id(self, id: impl Encode<'a, DB> + Type<DB> + Send + 'a) -> Self;
    fn and_tenant(self, scope: &TenantScope) -> Self;
}

impl<'a, DB: Database> WithTenantScope<'a, DB> for QueryBuilder<'a, DB>
where i64: Encode<'a, DB> + Type<DB>,
{
    fn where_id(mut self, id: impl Encode<'a, DB> + Type<DB> + Send + 'a) -> Self {
        self.push(" WHERE id = ").push_bind(id);
        self
    }

    fn and_tenant(mut self, scope: &TenantScope) -> Self {
        match scope {
            TenantScope::Single(tid) => {
                self.push(" AND tenant_id = ").push_bind(*tid);
                self
            }
            TenantScope::CrossTenant => self,
        }
    }
}
```

调用变 `QueryBuilder::new("SELECT ... FROM foo").where_id(&id).and_tenant(scope)`，每个点查询从 ~6 行降到 1-2 行。

## 4. 数据流

### Platform admin 跨租户点查询
```
platform_admin → GET /iam/users/{acme_user_id}
  → Handler: TenantScope = CrossTenant
  → service.get(acme_user_id, &scope)
    → QueryBuilder::new("SELECT ... FROM iam_users")
    → .where_id(acme_user_id)
    → .and_tenant(&scope)  // CrossTenant → no-op
  → 返回 acme 的 user record（200）
```

### 普通租户 admin 点查询
```
acme_admin → GET /iam/users/{globex_user_id}
  → Handler: TenantScope = Single(7)
  → service.get(globex_user_id, &scope)
    → QueryBuilder::new("SELECT ... FROM iam_users")
    → .where_id(globex_user_id)
    → .and_tenant(&scope)  → AND tenant_id = 7
  → 返回 0 行（404，globex 的 user 被过滤掉）
```

### INSERT（platform admin）
```
platform_admin → POST /iam/users (创建新用户)
  → Handler: TenantScope = CrossTenant
  → service.create(req, &scope)
    → tenant_id = scope.tenant_id().unwrap_or(1) → 1
  → INSERT INTO iam_users (..., tenant_id) VALUES (..., 1)
  // 资源归属 platform_admin 的 home 租户（default=1）
```

## 6. 风险

| 风险 | 严重度 | 缓解 |
|------|-------|------|
| service 签名 breaking change 影响其他 callers（tests、内部 service 间调用） | 中 | grep all callers + 一并更新；testcontainers 集成测试覆盖 |
| INSERT `scope.tenant_id().unwrap_or(1)` 对 CrossTenant 静默绑 default | 低 | 已设计如此（platform_admin 资源归自己租户）；不在范围内 |
| handler 双 extractor (`Principal` + `TenantScope`) 顺序敏感 | 低 | axum 文档明确 extractor 顺序无关；测试覆盖 |
| 漏改某处 handler 导致 tenant_id 仍从 Principal 传（编译错会暴露） | 低 | 编译期保证 `tenant_id` 字段从 Principal 移除后所有引用报错 |
