# Phase 4.1: notification-service Subscribe iam.user.created Event

> Spec ID: phase4.1-notification-welcome-template
> Status: IMPLEMENTING
> Created: 2026-06-27
> Phase: 4.x Small Iteration

## Overview

When IAM service creates a new user and sends iam.user.created event, notification-service automatically subscribes and generates a personal welcome announcement based on pre-configured template.

## Database Schema



## RabbitMQ

Queue: notification.iam-events
Binding: events exchange with routing_key iam.user.created

## Implementation

Modules:
- src/consumer/mod.rs - Consumer entry
- src/consumer/iam_events.rs - Event handler
- src/consumer/placeholder.rs - Placeholder replacement
- src/service/announcement_service.rs - Extend

## Placeholder Defaults

- username -> New User
- dept_name -> Platform
- created_at -> Just now

## Success Criteria

1. notification-service subscribes to iam.user.created
2. New user receives welcome announcement
3. Placeholders replaced correctly
4. Idempotency works
5. Template missing uses fallback
6. Tests pass
