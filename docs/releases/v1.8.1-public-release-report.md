## 4. PR #11 实施内容

PR：<https://github.com/luqizheng/lmms/pull/11>

- CLI SDK 发布命令增加显式 `--registry` override；不改变内网默认配置。
- Rust 公网发布使用 Cargo crates.io 默认 registry 语义：不传 `--registry`，内部 path 依赖转换为 version-only 依赖，不写入 Kellnr alias。
- npm 公网发布显式指定 `https://registry.npmjs.org/`，并让发布进程读取 setup-node 生成的认证配置。
- Workflow 串行执行 Rust → npm → Docker；每个阶段完成后进行公网 Registry 读回验证。
- Workflow 要求输入完整 expected SHA，核验 Tag 不可变且位于 main 历史中。
- 发布任务从指定 Tag 的 git worktree 构建，叠加 main 上已审核的发布工具代码；不会把 main 后续业务源码误当成 1.8.1 发布。
- 公网 Rust 工作目录移除仅用于本地开发的 `.cargo/config.toml`，避免 crates.io 被本地 source mirror 配置替换。
- Docker Hub 发布前检查目标 tag，拒绝覆盖已有 tag。
