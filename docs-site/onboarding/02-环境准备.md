## 2.2 各平台安装指引

### Windows

1. **Docker Desktop**：官网下载安装（设置里启用 WSL 2 based engine 仅影响 Docker 自身运行时，**编译与测试在 host 原生环境跑**）
2. **Rust**：在 **Windows 终端**（PowerShell / CMD）里运行：
   ```powershell
   winget install Rustlang.Rustup
   ```
   然后 `source $HOME/.cargo/env`（PowerShell 下用 `& "$env:USERPROFILE\.cargo\env.ps1"`）
3. **Visual Studio Build Tools**（**编译必需**）：`ring` / `aws-lc-sys` 有 C 依赖，需要 `cl.exe`。装任一即可：
   - [Visual Studio Build Tools 2022](https://visualstudio.microsoft.com/visual-cpp-build-tools/)（勾选「使用 C++ 的桌面开发」工作负载）
   - 或 Visual Studio 2022 / 18 社区版
   仓库脚本 `scripts/lib/host-runner.js` 会**自动发现**安装路径并注入 `INCLUDE` / `LIB` / `PATH`，无需手动进「Developer Command Prompt」。
4. **Node.js**：winget 安装 Node.js 20+ 或用 [fnm](https://github.com/Schniz/fnm)
5. **pnpm**：`npm install -g pnpm`
6. **swagger-ui 离线包**（避免 build.rs 联网下载失败）：
   ```powershell
   pnpm run assets:download
   ```

### macOS

1. **Docker Desktop**：官网下载安装，或 `brew install --cask docker`
2. **Rust**：`curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
3. **Node.js**：`brew install node` 或用 [fnm](https://github.com/Schniz/fnm)
4. **pnpm**：`npm install -g pnpm`

### Linux（Ubuntu / Debian 示例）

```bash
# Docker
sudo apt update
sudo apt install docker.io docker-compose-plugin
sudo usermod -aG docker $USER
newgrp docker

# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source $HOME/.cargo/env

# Node.js（fnm 方式）
curl -fsSL https://fnm.vercel.app/install | bash
fnm install 20
fnm use 20

# pnpm
npm install -g pnpm
```

## 2.3 验证安装（全部通过才算 OK）

在终端里逐条执行，**全都要有输出、不能报错**：

```bash
# 1. Docker
docker --version
# 期望输出：Docker version 24.x.x 或更高

# 2. Rust
cargo --version
# 期望输出：cargo 1.96.x 或更高

# 2b. Windows 额外：C 编译器（ring / aws-lc-sys 需要）
#     装了 VS Build Tools / VS 社区版即可，脚本自动发现，无需手动进 Developer Command Prompt
where.exe cl.exe
# 若找不到，说明需要安装 Visual Studio Build Tools（见 2.2 Windows 第 3 步）

# 3. Node.js
node --version
# 期望输出：v18.x.x 或更高

# 4. pnpm
pnpm --version
# 期望输出：8.x.x 或更高

# 5. Git
git --version
# 期望输出：2.40.x 或更高

# 6. Docker compose（新版插件）
docker compose version
# 期望输出：v2.x.x 或更高
```

## 2.5 Docker 镜像来源配置

本项目用到两类 Docker 镜像，可能来自不同仓库：

| 类别 | 包含 | 默认来源 |
|------|------|----------|
| **基础镜像** | rabbitmq / redis / nginx / mysql / consul / grafana 等 | Docker Hub (`hub.docker.com`) |
| **Builder 镜像** | rust / java / maven / node 等编译环境 | `zhcoder-docker-registry.com:8000` |

跑 `pnpm run setup` 时会进入交互式向导询问这两类来源（见 [第一次跑通 § 3.2](./03-第一次跑通.md)）：

```
=== Docker Registry Setup Wizard ===

  Base registry [留空=Docker Hub]: _
  Builder registry [zhcoder-docker-registry.com:8000]: _
```

- **内网环境**（Docker Hub 不可达）：基础镜像填 `zhcoder-docker-registry.com:8000/official`
- **外网环境**：直接回车用默认（Docker Hub + 默认 builder registry）
- **CI 自动化**：用 `CODER_BASE_REGISTRY` / `CODER_BUILDER_REGISTRY` 环境变量覆盖

完整说明见 [Docker Registry 来源配置指南](../guides/docker-registry-config.md)。
