## B. 术语表

| 术语 | 中文 | 含义 |
|------|------|------|
| **JWT** | JSON Web Token | 用于用户身份验证的令牌，包含 header.payload.signature 三段 |
| **RBAC** | 基于角色的访问控制 | 用户 → 角色 → 权限 的三层授权模型 |
| **OTel** | OpenTelemetry | 开源的观测性框架，统一收集 traces/metrics/logs |
| **Span** | 跨度 | 一次操作中一个阶段（如"查询数据库"），多个 span 组成 trace |
| **Trace** | 追踪 | 一次完整请求在所有服务中的处理过程，由多个 span 组成 |
| **Trace ID** | 追踪 ID | 唯一标识一次完整请求，跨服务传递用于串联日志 |
| **Consul** | — | HashiCorp 的服务发现与健康检查工具 |
| **Swagger** | — | OpenAPI 规范的 UI 展示工具，自动生成 API 文档 |
| **Rate Limit** | 限流 | 控制单位时间内允许的请求数量，防止过载 |
| **Token Bucket** | 令牌桶 | 限流算法，以固定速率放入令牌，请求需消耗令牌 |
| **E2E** | 端到端测试 | 从用户视角测试完整流程，覆盖前端+后端+数据库 |
| **Smoke Test** | 冒烟测试 | 最核心路径的快速测试，验证系统"能冒烟" |
| **Canary** | 灰度 | 新版本先给少量流量，验证无问题后再全量发布 |
| **Migration** | 迁移 | 数据库 schema 的变更脚本，支持回滚 |
| **SQLx** | — | Rust 的编译期 SQL 检查库 |
| **Pinia** | — | Vue 3 官方推荐的状态管理库 |
| **WSL2** | Windows Subsystem for Linux 2 | Windows 上运行 Linux 内核的子系统 |
| **OTLP** | OpenTelemetry Protocol | OpenTelemetry 的数据传输协议 |
| **PromQL** | Prometheus Query Language | Prometheus 的查询语言 |
